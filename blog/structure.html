Lists: Mutable Ordered Sequences

A list is a dynamic, zero-indexed array of object references. Items can be appended, reordered, modified, or removed in place.

# Initializing Lists shopping_list = [] fruits = ["apple", "banana", "orange", "grape"] numbers = [1, 2, 3, 4, 5] mixed_list = ["hello", 42, True, 3.14]

Common List Methods

tasks = ["read", "exercise", "code"] tasks.append("sleep") # Append item to the end tasks.insert(1, "eat") # Insert item at index 1 tasks.remove("read") # Remove first occurrence of value finished = tasks.pop() # Remove and return the final element tasks.sort() # In-place alphabetical/numerical sort sorted_copy = sorted(tasks, reverse=True)# Return a fresh sorted list copy

List Comprehensions

nums = [1, 2, 3, 4, 5] squares = [n * n for n in nums] evens = [n for n in nums if n % 2 == 0] pairs = [(a, b) for a in [1, 2] for b in ['x', 'y']]

Tuples: Immutable Ordered Collections

Tuples are fixed-length sequences. Once instantiated, values cannot be added, reassigned, or removed. This property makes them hashable (usable as dictionary keys) and memory-efficient.

# Initializing Tuples coordinates = (10, 20) colors = ("red", "green", "blue") single_item = (42,) # Note the mandatory trailing comma for 1-tuples

Unpacking Mechanics

person = ("Sam", 21, "Student") name, age, role = person # Extended slicing unpack (Python 3+) first, *middle, last = [1, 2, 3, 4, 5] # first = 1, middle = [2, 3, 4], last = 5

Dictionaries: Hash Maps & Key-Value Mappings

Dictionaries store key-value associations providing average $O(1)$ lookup, insertion, and deletion complexity. Keys must be hashable and immutable.

student = { "name": "Sarah", "age": 19, "major": "Biology" } # Accessing keys print(student["name"]) print(student.get("gpa", 0.0)) # Safe fallback, avoids KeyError # Mutation student["gpa"] = 3.7 student["age"] = 20

Dictionary Comprehensions

nums = [1, 2, 3, 4] square_map = {n: n * n for n in nums}

Strings: Text Primitives & Encodings

Python strings are immutable UTF-8 sequence buffers. String operations always return fresh string instances.

sentence = "learn python the smart way" words = sentence.split(" ") joined = "-".join(words) fstring = f"Result: {words[0].upper()}"

Advanced Indexing & Slicing Semantics

Slices use the syntax sequence[start:stop:step] on half-open ranges: [start, stop).

nums = list(range(10)) print(nums[2:7]) # [2, 3, 4, 5, 6] print(nums[:5]) # [0, 1, 2, 3, 4] print(nums[5:]) # [5, 6, 7, 8, 9] print(nums[::2]) # [0, 2, 4, 6, 8] print(nums[::-1]) # Reversed copy
