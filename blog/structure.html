📝 Lists - The Flexible Container

What is a List?

A list is an ordered collection of items that can be changed (mutable). Think of it like a shopping list where you can add, remove, or modify items.

# Creating Lists shopping_list = [] # Empty list fruits = ["apple", "banana", "orange", "grape"] numbers = [1, 2, 3, 4, 5] mixed_list = ["hello", 42, True, 3.14]

💡 Hint:
Remember to use square brackets [] and separate items with commas. Strings need quotes!

Common List Methods

tasks = ["read", "exercise", "code"] tasks.append("sleep") # add at end tasks.insert(1, "eat") # insert at index 1 tasks.remove("read") # remove first occurrence done = tasks.pop() # remove last and return it count_code = tasks.count("code") tasks.sort() # in-place sort sorted_tasks = sorted(tasks, reverse=True) # new sorted list

List Comprehensions

nums = [1, 2, 3, 4, 5] squares = [n*n for n in nums] evens = [n for n in nums if n % 2 == 0] pairs = [(a, b) for a in [1,2] for b in ['x','y']] print(squares) print(evens) print(pairs)

🔒 Tuples - The Immutable Container

What is a Tuple?

A tuple is an ordered collection of items that cannot be changed (immutable). Think of it like coordinates (x, y) that represent a fixed point.

# Creating Tuples coordinates = (10, 20) colors = ("red", "green", "blue") mixed_tuple = ("John", 25, "Engineer") # Single item tuple (note the comma!) single_item = (42,)

Tuple vs List - When to Use Which?

# Use tuples for fixed data point = (10, 20) # Coordinates don't change rgb = (255, 128, 0) # Color values are fixed # Use lists for changeable data shopping = ["milk", "eggs"] # Can add more items scores = [85, 90, 78] # Scores can be updated

Tuple Unpacking

person = ("Sam", 21, "Student") name, age, role = person print(name, age, role) # Extended unpacking first, *middle, last = [1,2,3,4,5] print(first, middle, last)

🗝️ Dictionaries - The Key-Value Container

What is a Dictionary?

A dictionary is a collection of key-value pairs. Think of it like a real dictionary where you look up a word (key) to find its definition (value).

# Creating Dictionaries student = { "name": "Sarah", "age": 19, "major": "Biology", "gpa": 3.7 } # Accessing values print(student["name"]) # "Sarah" print(student.get("height", "N/A")) # "N/A" (default value)

🎯 Exercise 3.1: Create Your Dictionary

Create a dictionary representing your favorite movie with title, director, year, and rating.

Working with Dictionaries

student = {"name": "Sarah", "age": 19} # Adding/updating values student["major"] = "Biology" # Add new key-value pair student["age"] = 20 # Update existing value # Get all keys, values, or items print(student.keys()) # dict_keys(['name', 'age', 'major']) print(student.values()) # dict_values(['Sarah', 20, 'Biology']) print(student.items()) # key-value pairs # Check if key exists if "name" in student: print(f"Student name: {student['name']}")

Dictionary Comprehensions

nums = [1, 2, 3, 4] square_map = {n: n*n for n in nums} even_map = {n: 'even' for n in nums if n % 2 == 0} print(square_map) print(even_map)

🔤 Strings - Text Data and Operations

Creating and Combining Strings

greeting = "Hello" name = 'Alice' full = greeting + ", " + name + "!" template = f"{greeting}, {name}!" multiline = """This is a multi-line string.""" print(full) print(template) print(multiline)

Common String Methods

text = " Python Programming " print(text.strip()) # remove leading/trailing spaces print(text.lower()) # to lowercase print(text.upper()) # to uppercase print(text.replace(" ", "-")) # replace spaces with hyphens print("prog" in text.lower()) # membership test print(text.find("Pro")) # first index or -1

Split, Join, and Format

sentence = "learn python the smart way" words = sentence.split(" ") joined = "-".join(words) formatted = "Hello {}, your score is {}".format("Alex", 95) fstring = f"Hello {'Alex'.upper()}, your score is {95}" print(words) print(joined) print(formatted) print(fstring)

Indexing and Slicing Strings

s = "Python" print(s[0]) # 'P' print(s[-1]) # 'n' print(s[1:4]) # 'yth' print(s[::-1]) # 'nohtyP' (reverse)

🧭 Advanced Indexing & Slicing

Slicing Syntax Recap

# sequence[start:stop:step] nums = list(range(10)) print(nums[2:7]) # [2, 3, 4, 5, 6] print(nums[:5]) # [0, 1, 2, 3, 4] print(nums[5:]) # [5, 6, 7, 8, 9] print(nums[::2]) # [0, 2, 4, 6, 8] print(nums[1:8:3]) # [1, 4, 7] print(nums[::-1]) # reversed

Copying vs Referencing

a = [1, 2, 3] b = a # reference (same list) c = a[:] # shallow copy (new list) a.append(4) print(b) # [1, 2, 3, 4] print(c) # [1, 2, 3]

Negative Index/Step

letters = list("abcdefghij") print(letters[-3:]) # last three print(letters[:-3]) # all but last three print(letters[-1:-6:-2])# ['j', 'h', 'f']
