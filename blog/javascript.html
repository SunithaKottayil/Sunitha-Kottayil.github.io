1. Your First JavaScript Program

Let’s write the classic “Hello, World!” program to get started. Open your browser console (F12 or right-click → Inspect → Console) and copy-paste this:

console.log("Hello, World!");

This prints Hello, World! in the console.

Tip: Use console.log() to display information at any point while coding.

2. JavaScript Basics You Need to Know

2.1 Variables and Data Types

Variables store information so you can use and change it later. JavaScript has three ways to declare variables:

  • var (older, avoid if possible)
  • let (modern, block-scoped)
  • const (constant, can’t change after assignment)

Common data types:

  • number — for all numeric values
  • string — text surrounded by quotes
  • boolean — true or false
  • null and undefined — special “empty” values
  • object — collections and more complex data
// Declare variables
const name = "Alice";
let age = 25;
let isJavaScriptFun = true;

console.log(name, age, isJavaScriptFun);
Quiz 2: Which keyword should you use for variables you plan to change?



2.2 Operators

JavaScript uses operators to perform math, compare values, and more:

  • Arithmetic: +, -, *, /, %
  • Assignment: =, +=, -=, etc.
  • Comparison: ==, ===, !=, !==, >, <
  • Logical: && (and), || (or), ! (not)
let x = 5;
let y = 10;
console.log(x + y); // 15
console.log(x === 5 && y === 10); // true

2.3 Conditionals (if, else, else if)

let age = 18;

if (age >= 18) {
  console.log("You can vote!");
} else if (age > 13) {
  console.log("You are a teenager.");
} else {
  console.log("You are a child.");
}
Quiz 3: What keyword checks a condition in JavaScript?



2.4 Loops (for, while, do-while)

// For loop:
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

// While loop:
let count = 1;
while (count <= 5) {
  console.log(count);
  count++;
}

// Do-while loop:
let j = 1;
do {
  console.log(j);
  j++;
} while (j <= 5);
Quiz 4: Which loop runs the code at least once, even if the condition is false?



2.5 Functions

Functions are reusable blocks of code you can call anytime.

function greet(name) {
  console.log("Hello, " + name + "!");
}

greet("Samantha"); // Outputs: Hello, Samantha!

// Arrow function (shorter syntax)
const add = (a, b) => a + b;
console.log(add(2, 3)); // 5

3. Working with Data Structures

3.1 Arrays

// Array creation and basic use:
let fruits = ["Apple", "Banana", "Cherry"];
console.log(fruits[0]); // Apple

// Looping over arrays:
for (let fruit of fruits) {
  console.log(fruit);
}

3.2 Objects

// Object with properties:
const person = {
  name: "John",
  age: 30,
  greet() {
    console.log("Hi, I'm " + this.name);
  }
};

person.greet(); // Hi, I'm John

4. The DOM & Events (Browser JS)

JavaScript controls web pages through the Document Object Model (DOM). You can select elements, change them, and respond to events.

// Change text of an element with id="demo"
document.getElementById("demo").innerText = "Hello from JS!";

// Listen for clicks
document.getElementById("myButton").addEventListener("click", function() {
  alert("Button clicked!");
});

The DOM lets JavaScript interact with your webpage's elements and respond to user actions.

5. Advanced JavaScript Concepts

5.1 ES6+ Features

  • Let and Const: Block-scoped variables
  • Arrow Functions: Shorter syntax
  • Template Literals: Multi-line strings and interpolation
  • Destructuring: Extract properties from objects/arrays
  • Spread/Rest Operators: Expand or collect elements/arguments
  • Modules: Import/export JS code
// Template literals
const name = "Anna";
console.log(`Hello, ${name}!`);

// Destructuring
const user = { id: 1, username: "user1" };
const { id, username } = user;
console.log(id, username);

// Spread operator
const nums = [1, 2, 3];
const moreNums = [...nums, 4, 5];
console.log(moreNums);

5.2 Promises & Async/Await

Handle asynchronous operations cleanly:

// Promise example
function wait(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

wait(1000).then(() => console.log("Waited 1 second"));

// Async/await example
async function asyncWait() {
  await wait(1000);
  console.log("Waited 1 second (async/await)");
}
asyncWait();

5.3 Classes & Prototypes

// Class syntax (ES6+)
class Person {
  constructor(name) {
    this.name = name;
  }
  greet() {
    console.log(`Hi, I'm ${this.name}`);
  }
}

const alice = new Person("Alice");
alice.greet(); // Hi, I'm Alice

try {

} finally {
