  • You can change a variable's value and type at any time

PREREQUISITE 2 Print & Input

Communication between your program and users happens through printing output and receiving input.

Printing Output

F-String Tips:
  • Start string with f before the quote: f"text"
  • Put variables and expressions inside curly braces: {variable}
  • Can do math inside: {5 + 3} outputs 8
  • Format numbers: {number:.2f} shows 2 decimal places

Getting User Input

input_basics.py
Important: The input() function ALWAYS returns a string, even if the user types a number. You must convert it using int() or float() to do math with it.

PREREQUISITE 8 Working with CSV Files

CSV (Comma Separated Values) files are a simple way to store tabular data. They're perfect for storing quiz questions!

Understanding CSV Format

What is CSV?

A CSV file stores data in plain text where:

  • Each line represents one row of data
  • Values are separated by commas
  • First row typically contains column headers
