Introduction

This reference walks through the implementation of an interactive command-line quiz application. Rather than bundling monolithic code, we break down each operational prerequisite before integrating them into a maintainable script architecture.

Architectural Deliverables

  • Parse raw CSV records into structured in-memory dictionaries.
  • Render formatted CLI multiple-choice questions with validated selection indices.
  • Evaluate user input deterministically and calculate metrics (absolute score and percentage).
  • Encapsulate reusable procedures within functions to prevent global scope pollution.
Execution Context: The code editors on this page run in an isolated client-side interpreter. Standard I/O and loop evaluations execute inside your browser window.

MODULE 01 Variables & Fundamental Types

Variables serve as symbolic references bound to memory-allocated objects. Python is strongly, dynamically typed; variables point to values that enforce runtime operational rules.

Strings (str)

Immutable UTF-8 character sequences enclosed in quotes.

Integers (int)

Arbitrary-precision signed whole numeric values.

Floats (float)

Standard IEEE 754 double-precision decimal numbers.

Booleans (bool)

Logical singletons evaluating to True or False.

MODULE 02 Standard Stream I/O

CLI interaction relies on standard output (sys.stdout) and standard input (sys.stdin). Modern implementations prefer formatted string literals (f-strings) over concatenation for performance and legibility.

Type Conversion Rule: input() always returns a str object. Arithmetic operations on numeric inputs require explicit casting via int() or float().
