1. What is Power BI?

  • Power BI is a Microsoft tool for visualizing, analyzing, and sharing data from many sources.
  • You can import data (Excel, CSV, web, databases), transform & clean it, build interactive reports and dashboards, and share them online.
  • It's available as Power BI Desktop (Windows app) and Power BI Service (web version).

Data sources → Power Query → Model & DAX → Visualizations → Dashboards & Publishing
Power BI is the “control center” for all your business data. You can create drag-and-drop dashboards and discover insights visually!

2. Power BI Desktop: The Workflow

  1. Get Data: Connect to a file or database (Excel, SQL, etc.).
  2. Transform Data (Power Query): Clean, shape, and filter your data.
  3. Model: Build relationships between tables; create calculated columns/measures using DAX.
  4. Visualize: Create charts, graphs, maps, and other interactive visuals.
  5. Publish: Share your report/dashboards in the Power BI Service.
# Typical steps:
1. Home > Get Data > Excel (choose your dataset)
2. Home > Transform Data (launch Power Query)
3. Home > Close & Apply (load cleaned data)
4. Insert visuals (bar, pie, line chart, etc.)
5. Modeling > New Measure (write DAX)
6. File > Publish to Power BI Service

3. DAX: What, Why, Where?

DAX (Data Analysis Expressions) is the formula language of Power BI—like Excel formulas, but tuned for interactive analytics. Use it for:

  • New columns and calculated fields
  • Measures (dynamic calculations like SUM of sales YTD, averages, etc.)
  • Custom tables for slicing/dicing your data


DAX bridges data and visual analytics, letting you ask business questions with code.
DAX formulas can be created using “New Measure” (for calculations in visuals) or “New Column” (for extra data on each row).

4. Essential and Important DAX Functions

  • CALCULATE: Change/filter context to compute dynamic values.
    CALCULATE(SUM(Sales[Amount]), Sales[Region]="West", YEAR(Sales[Date])=2022)
  • SUM: Adds up all values in a column.
    SUM(Sales[Amount])
  • AVERAGE: Calculates the mean value.
    AVERAGE(Sales[Amount])
  • COUNT / COUNTA / DISTINCTCOUNT: Counts total rows, non-blank rows, or unique values.
    COUNT(Sales[OrderID]) DISTINCTCOUNT(Sales[CustomerID])
  • MIN / MAX: Finds smallest/largest value in a column.
  • SUMX: Iterates across a table, doing row-by-row calculation and summing results.
    SUMX(Sales, Sales[Quantity] * Sales[Price])
  • FILTER: Returns a subset of table rows based on a condition.
    FILTER(Sales, Sales[Region]="West")
  • RELATED: Pulls in fields from related tables (like VLOOKUP).
    RELATED(Products[Category])
  • ALL: Ignores existing filters (handy for percent-of-total, e.g. SUM(Sales[Amount]) / CALCULATE(SUM(Sales[Amount]), ALL(Sales))).
  • IF: Logical branching—like Excel’s IF.
    IF(Sales[Amount] > 1000, "Big", "Small")
  • AND / OR / SWITCH: More logic chaining and multibranch.
  • DATEADD / DATESYTD / SAMEPERIODLASTYEAR: Built-in “time intelligence”—essential for trends, YoY, growth, etc.
  • RANKX: Assigns ranks to table rows.
    RANKX(ALL(Sales), SUM(Sales[Amount]))
  • SUMMARIZE / GROUPBY: Returns a summary table grouped by chosen columns.
    SUMMARIZE(Sales, Customers[Country], "Total", SUM(Sales[Amount]))
  • ADDCOLUMNS: Adds calculated columns to a table.
  • CROSSFILTER: Controls filter direction in relationships (advanced modeling).
Pro tip: Most DAX functions work on columns and tables—not single cells. Think in table logic, not spreadsheet cells[6][12][7][9][15].

5. Example DAX Calculations

-- Total Sales
Total Sales = SUM(Sales[Amount])

-- Total Revenue
Total Revenue = SUMX(Sales, Sales[Quantity] * Sales[UnitPrice])

-- Sales Last Year
Sales Last Year = CALCULATE(SUM(Sales[Amount]), SAMEPERIODLASTYEAR(Sales[Date]))

-- Running Total
Cumulative Sales = CALCULATE([Total Sales], FILTER(ALL(Sales[Date]), Sales[Date] <= MAX(Sales[Date])))

-- Category Rank
Category Rank = RANKX(ALL(Products[Category]), [Total Sales],, DESC)
Measures let you easily build KPIs, percent-of-total, trends, and more for every dashboard visual!
