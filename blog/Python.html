🐍 Learning Python

Hey there! Python is like the friendly programming language that everyone loves. It's perfect for beginners because it reads almost like English, and it's powerful enough to build just about anything. Let's start from the very beginning and work our way up!

1. What is Python?

  • Python is like the Swiss Army knife of programming languages - it can do just about anything!
  • You can build websites, analyze data, automate boring tasks, create games, work with AI, and so much more.
  • Best part? It's completely free and works on Windows, Mac, and Linux.

Python is everywhere - from your favorite websites to the apps on your phone!

2. Getting Started

  1. Install Python from python.org/downloads. Don't worry - it's super easy and takes just a few minutes!
  2. Write code in IDLE (comes with Python), or try replit.com or Jupyter notebooks online if you want to start coding right away.
  3. To run your code, open your editor, type some commands, then click "Run" or type python filename.py in your terminal.
Quick tip: The interactive shell (just type python in your terminal) lets you try commands instantly without saving files!

4. Variables - Storing Information

  • int: whole numbers like 5 or 42
  • float: decimal numbers like 3.14 or 2.5
  • str: text (strings) like "Hello" or "Python is awesome!"
  • bool: True/False values (like yes/no questions)
  • list, tuple, dict: more advanced ways to store data (we'll get to these later)
age = 21
height = 1.70
name = "Alex"
is_cool = True

print(name, age, height, is_cool)

5. Getting Input from Users

name = input("What is your name? ")
print("Hello,", name)

Use input() to ask the user for information. It always gives you text, so if you want numbers, you'll need to convert them with int() or float().

6. Making Decisions - if, elif, else

score = int(input("Your score: "))
if score >= 90:
    print("Great job!")
elif score >= 70:
    print("Good effort.")
else:
    print("Keep practicing.")

7. Loops - Doing Things Over and Over

# Print numbers 1-5
for i in range(1, 6):
    print(i)

# While loop - keep going until something changes
count = 5
while count > 0:
    print(count)
    count -= 1

8. Functions - Reusable Code

def greet(name):
    print("Hello,", name)

greet("Sam")

Functions are like little recipes for your code. You write them once and use them over and over. They can take information (parameters), do something with it, and even give you back results.

9. Lists, Tuples, and Dictionaries - Storing Multiple Things

Lists (you can change them):

numbers = [10, 20, 30]
print(numbers[0])  # 10
numbers.append(40)
print(numbers)  # [10, 20, 30, 40]

Tuples (you can't change them):

coords = (4, 5)
print(coords[1])  # 5

Dictionaries (like a phone book - name and number pairs):

person = {"name": "Alex", "age": 30}
print(person["name"])
person["country"] = "France"

10. Slicing Lists and List Comprehensions

mylist = [1, 2, 3, 4, 5]
print(mylist[1:4])  # [2, 3, 4] - get items from position 1 to 3

# List comprehension - a fancy way to make lists
evens = [x for x in range(10) if x % 2 == 0]
print(evens)  # [0, 2, 4, 6, 8]

11. Handling Errors Gracefully

try:
    result = 10 / 0
except ZeroDivisionError:
    print("You can't divide by zero!")
finally:
    print("This always runs")

Use try/except to catch errors and handle them nicely instead of letting your program crash.

12. Object-Oriented Programming - Classes and Objects

class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(self.name, "says woof!")

fido = Dog("Fido")
fido.bark()  # Fido says woof!
  • Classes are like blueprints for creating objects.
  • Objects are things you create from those blueprints (like building a house from plans).
  • Methods are the things objects can do (like a dog can bark, sit, fetch).
  • You can use inheritance (one class can inherit from another), properties, and special methods.

13. Modules and Packages - Using Other People's Code

Organize your code into modules (Python files) and packages (folders of modules). Import code with: 

import math
print(math.sqrt(16))  # 4.0

Install external packages using pip:

pip install requests

Then import requests in your Python code to use it.

15. Some Cool Advanced Stuff

Decorators

def shout(fn):
    def wrapper():
        return fn().upper()
    return wrapper

@shout
def greet():
    return "hello"

print(greet())  # HELLO

Generators & Iterators

def countdown(n):
    while n > 0:
        yield n
        n -= 1

for i in countdown(3):
    print(i)

16. Lambda Functions and Map/Filter/Reduce

nums = [1, 2, 3]
squared = list(map(lambda x: x ** 2, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
print(squared)  # [1, 4, 9]
print(evens)    # [2]

17. List Comprehensions and Advanced Data Structures

matrix = [[1, 2], [3, 4]]
flat = [num for row in matrix for num in row]
print(flat)  # [1, 2, 3, 4]

myset = {1, 2, 3}  # Sets are like lists but with no duplicates
