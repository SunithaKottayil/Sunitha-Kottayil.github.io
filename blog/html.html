1. What is HTML?

HTML (HyperText Markup Language) is the foundational markup language that structures web pages. It tells browsers how to display text, images, links, and other content.

Think of HTML as the skeleton of a webpage, giving structure and meaning that CSS and JavaScript build upon.


HTML provides the structure, CSS the styling, and JavaScript the behavior of web pages.

2. Setting Up Your First HTML Document

Start simple: open any text editor (Notepad, VS Code) and type this basic HTML template:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my very first webpage.</p>
  </body>
</html>

Save as index.html, then open this file in your browser to see your first page live.

Tip: The <!DOCTYPE html> declaration ensures the browser uses the latest HTML standards.

3. Understanding HTML Document Structure

Your HTML page has two main parts:

  • <head>: Meta-information about your page (title, character set, CSS links), not visible in the main page.
  • <body>: Visible content like text, images, links, videos, forms, and more.

Use semantic tags inside <body> to add meaning — we'll cover those soon!


The basic structure of an HTML document.
<head> is metadata, <body> is visible content.

4. Basic HTML Elements and Tags

HTML elements are defined by tags with angle brackets, usually opening and closing tags:

<tagname>content</tagname>

Common basic tags include:

  • <h1>...</h1> to <h6>...</h6> — Headings with descending importance.
  • <p>...</p> — Paragraphs.
  • <a href="url">...</a> — Hyperlinks.
  • <img src="..." alt="..." /> — Display images.
  • <ul> and <ol> — Unordered and ordered lists with <li> items.
  • <div> and <span> — Generic containers for layout and styling.

5. Attributes: Adding Details to Elements

Attributes provide extra info inside the opening tag. For example:

<a href="https://example.com" target="_blank">Visit Example</a>

Common attributes:

  • href, src, alt for links and images.
  • id, class, for CSS styling and scripting.
  • title to show tooltips.
  • target to specify link opening behavior.

6. Semantic HTML: Giving Meaning to Web Content

Semantic tags improve accessibility, SEO, and maintainability. Use them meaningfully:

  • <header>, <footer>: Page header and footer.
  • <nav>: Navigation menus.
  • <article>, <section>: Blocks of related content.
  • <aside>: Side content like ads or tips.
  • <main>: Main content.
  • <figure>, <figcaption>: Images with captions.

Using semantic tags structures your page clearly, helping browsers and assistive tech.

7. Working With Images and Multimedia

Add images:

<img src="path/to/image.jpg" alt="Description of image" width="400" />

Embed videos and audio:

<video controls width="600">
  <source src="video.mp4" type="video/mp4">
  Your browser does not support the video tag.
</video>

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Your browser does not support the audio tag.
</audio>

8. Creating Links and Navigation

Make links with <a> tags:

<a href="https://www.example.com" target="_blank" rel="noopener noreferrer">External Link</a>

Internal page anchors:

<a href="#section1">Go to Section 1</a>
...
<h2 id="section1">Section 1</h2>

Examples:

</ul>

<ol>

<dl>

10. Forms and Input Elements

Forms collect user input:

<form action="/submit" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name" required />

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required />

  <label>Choose a color:</label>
  <select name="color">
    <option value="red">Red</option>
    <option value="green">Green</option>
  </select>

  <input type="submit" value="Send" />
</form>

There are many input types: text, password, checkbox, radio, date, number, file, and more, each suited for different data.

  </thead>
  <tbody>
    <tr><td>Alice</td><td>30</td></tr>
    <tr><td>Bob</td><td>25</td></tr>
  </tbody>

12. HTML5 Semantic & Advanced Elements

  • <section>: Logical sections of content.
  • <article>: Self-contained content.
  • <header>, <footer>: Intro and footer of sections.
  • <figure>, <figcaption>: Images with captions.
  • <mark>: Highlighted text.
  • <details>, <summary>: Collapsible content sections.
  • <dialog>: Modal dialog boxes.

13. Accessibility & Best Practices

  • Provide meaningful alt text for images for screen readers.
  • Use semantic tags for better navigation (headers, navigation, main, etc.).
  • Label form inputs clearly; associate <label> with controls using for and id.
  • Ensure keyboard navigation is smooth.
  • Use ARIA roles and attributes when necessary.
  • Validate your HTML code with tools like the W3C Validator.

14. HTML APIs and Integrations

Modern web pages integrate with APIs like:

  • Canvas API — drawing graphics.
  • Web Storage API — storing data locally in the browser.
  • Geolocation API — location information.
  • Drag and Drop API — interactive dragging UI.
  • Web Workers — background threads.

Learn JavaScript to harness these APIs fully!
