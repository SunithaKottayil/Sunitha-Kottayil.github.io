Learn HTML from Scratch

A practical guide to building web pages with HTML. No prior experience needed - we'll start with the basics and work our way up to creating complete web pages.

What is HTML?

HTML stands for HyperText Markup Language. It's the standard language used to create web pages. Think of HTML as the foundation of a house - it provides the structure that everything else is built on.

HTML uses "tags" to mark up content and tell the browser how to display it. For example, you can mark text as a heading, a paragraph, or a link to another page.

Why learn HTML? HTML is essential for web development. Even if you use website builders, understanding HTML helps you customize and troubleshoot your sites.

Your First HTML Page

Every HTML page follows the same basic structure. Let's create a simple page:

<html lang="en"> <head> <meta charset="UTF-8"> <title>My First Page</title> </head> <body> <h1>Welcome to My Website</h1> <p>This is my first HTML page!</p> </body> </html>

Breaking it Down

  • <!DOCTYPE html> - Tells the browser this is an HTML5 document
  • <html> - The root element that contains everything
  • <head> - Contains information about the page (not visible to users)
  • <body> - Contains the visible content of your page
Try it yourself: Copy this code into a text editor, save it as "index.html", and open it in your web browser.

Essential HTML Elements

Headings and Text

HTML provides six levels of headings and various text elements:

<h1>Main Heading</h1> <h2>Section Heading</h2> <h3>Subsection Heading</h3> <p>This is a paragraph of text.</p> <p>You can make text <strong>bold</strong> or <em>italic</em>.</p>

Links and Images

Connect pages and add visual content:

<a href="https://www.example.com">Visit Example.com</a> <a href="about.html">About Page</a> <img src="photo.jpg" alt="A beautiful sunset">
Important: Always include the alt attribute for images. It helps screen readers and shows if the image fails to load.

Lists

Organize information with lists:

Unordered List (bullets)

<ul> <li>Apples</li> <li>Bananas</li> <li>Oranges</li> </ul>

Ordered List (numbers)

<ol> <li>First step</li> <li>Second step</li> <li>Third step</li> </ol>

Semantic HTML

Semantic elements clearly describe their meaning to both browsers and developers. They improve accessibility and SEO.

Element Purpose Example Use
<header> Page or section header Site logo and navigation
<nav> Navigation links Main menu, breadcrumbs
<main> Main content Primary page content
<article> Standalone content Blog post, news article
<section> Content section Chapter, tab content
<footer> Page or section footer Copyright, contact info

Semantic Page Structure

<header> <h1>My Blog</h1> <nav> <a href="/">Home</a> <a href="/about">About</a> </nav> </header> <main> <article> <h2>My First Post</h2> <p>Welcome to my blog...</p> </article> </main> <footer> <p>© 2024 My Blog</p> </footer>

HTML Forms

Forms let users interact with your website by submitting information:

<form> <label for="name">Your Name:</label> <input type="text" id="name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email" required> <label for="message">Message:</label> <textarea id="message" name="message" rows="4"></textarea> <button type="submit">Send Message</button> </form>

Common Input Types

  • text - Single line text
  • email - Email addresses (with validation)
  • password - Hidden text
  • number - Numeric input
  • date - Date picker
  • checkbox - Multiple choice
  • radio - Single choice from options

Adding Media

Images

<img src="landscape.jpg" alt="Mountain landscape at sunset" width="600">

Videos

<video controls width="600"> <source src="movie.mp4" type="video/mp4"> <source src="movie.webm" type="video/webm"> Your browser doesn't support video. </video>

Audio

<audio controls> <source src="podcast.mp3" type="audio/mpeg"> Your browser doesn't support audio. </audio>

Best Practices

Write Clean, Accessible HTML

  • Use semantic elements that describe your content
  • Always include alt text for images
  • Associate labels with form inputs using for and id
  • Use headings in order (h1, then h2, then h3, etc.)
  • Validate your HTML to catch errors

Performance Tips

  • Optimize image sizes and formats
  • Use appropriate image formats (JPEG for photos, PNG for graphics)
  • Keep your HTML structure simple and clean
  • Use external CSS and JavaScript files
Next Steps: Once you're comfortable with HTML, learn CSS to style your pages and JavaScript to add interactivity!
