1. HTML Basics

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of web pages using markup.

Basic HTML Document

Every HTML document has the same basic structure:

1 <!DOCTYPE html>
2 <html lang="en">
3 <head>
4 <meta charset="UTF-8" />
5 <meta name="viewport" content="width=device-width, initial-scale=1.0" />
6 <title>Page Title</title>
7 </head>
8 <body>
9 <h1>This is a heading</h1>
10 <p>This is a paragraph.</p>
11 </body>
12 </html>

This is a paragraph.

Note: Save your HTML files with a .html extension and open them in a web browser to see the results.

2. Document Structure

Let's break down the parts of an HTML document:

  • <!DOCTYPE html> - Declares this as an HTML5 document
  • <html> - Root element of the page
  • <head> - Contains metadata about the document
  • <body> - Contains the visible page content

Head Section

The head contains important information about your page:

1 <head>
2 <meta charset="UTF-8">
3 <meta name="viewport" content="width=device-width, initial-scale=1.0">
4 <title>My Website</title>
5 <meta name="description" content="A brief description of my website">
6 </head>

3. HTML Elements

Headings

HTML provides six levels of headings:

1 <h1>Main Heading</h1>
2 <h2>Section Heading</h2>
3 <h3>Subsection Heading</h3>
4 <h4>Minor Heading</h4>
5 <h5>Small Heading</h5>
6 <h6>Smallest Heading</h6>

Paragraphs and Text

1 <p>This is a regular paragraph.</p>
2 <p>Text can be <strong>bold</strong> or <em>italic</em>.</p>
3 <p>You can also <mark>highlight</mark> text.</p>

Links

1 <a href="https://example.com">External Link</a>
2 <a href="about.html">Internal Link</a>
3 <a href="mailto:email@example.com">Email Link</a>

Lists

<!-- Unordered List --> <ul> <li>First item</li> <li>Second item</li> <li>Third item</li> </ul> <!-- Ordered List --> <ol> <li>Step one</li> <li>Step two</li> <li>Step three</li> </ol>

4. Forms

Forms allow users to submit data to your website:

<form action="/submit" method="post"> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email" required> <button type="submit">Submit</button> </form>

Input Types

  • text - Single line text
  • email - Email address
  • password - Hidden text
  • number - Numeric input
  • checkbox - Checkboxes
  • radio - Radio buttons
  • file - File upload

5. Semantic HTML

Semantic elements provide meaning to your content:

Element Purpose
<header> Page or section header
<nav> Navigation links
<main> Main content
<article> Standalone content
<section> Content section
<footer> Page footer
<header> <h1>My Website</h1> <nav> <a href="/">Home</a> <a href="/about">About</a> </nav> </header> <main> <article> <h2>Article Title</h2> <p>Article content goes here...</p> </article> </main> <footer> <p>© 2024 My Website</p> </footer>
Best Practice: Use semantic elements to improve accessibility and SEO. Screen readers and search engines understand the structure better.
