1. What is HTML?

HTML (HyperText Markup Language) is the standard language for creating web pages. It describes the structure and content of a webpage using elements and tags.

Think of HTML as the skeleton of a webpage—it provides structure that browsers can understand and display. CSS handles the styling, and JavaScript adds interactivity.

Important

HTML is a markup language, not a programming language. It structures content but doesn't perform calculations or logic operations.

2. Getting Started

You can write HTML using any text editor. For beginners, try Notepad (Windows) or TextEdit (Mac). For a better experience, consider VS Code or Sublime Text.

Your First HTML Document

Create a new file and save it with a .html extension. Here's a basic structure:

index.html
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Web Page</title> </head> <body> <h1>Welcome to My Website</h1> <p>This is my first HTML page!</p> </body> </html>

Save this as "index.html" and open it in your web browser to see the result:

file:///path/to/index.html

Welcome to My Website

This is my first HTML page!

3. Document Structure

Every HTML document follows the same basic pattern:

  • <!DOCTYPE html> - Tells the browser this is HTML5
  • <html> - Root element containing everything
  • <head> - Metadata not visible to users
  • <body> - Visible page content

4. HTML Elements

Headings

HTML provides six heading levels:

headings.html
<h1>Main Title</h1> <h2>Section Title</h2> <h3>Subsection</h3> <h4>Minor Heading</h4> <h5>Small Heading</h5> <h6>Smallest Heading</h6>

Text and Formatting

text-formatting.html
<p>This is a paragraph.</p> <p>Make text <strong>bold</strong> or <em>italic</em>.</p> <p>You can also <mark>highlight</mark> text.</p>

Links

links.html
<a href="https://example.com">External Link</a> <a href="about.html">Internal Link</a> <a href="mailto:hello@example.com">Email Link</a>

Lists

lists.html
<!-- Unordered list --> <ul> <li>Item one</li> <li>Item two</li> <li>Item three</li> </ul> <!-- Ordered list --> <ol> <li>First step</li> <li>Second step</li> <li>Third step</li> </ol>

5. Semantic HTML

Semantic elements clearly describe their meaning, improving accessibility and SEO.

Element Purpose Example Use
<header> Page or section header Site logo, navigation
<nav> Navigation links Main menu, breadcrumbs
<main> Primary content Main page content
<article> Standalone content Blog post, news article
<section> Content section Chapter, topic grouping
<footer> Page or section footer Copyright, contact info
semantic-layout.html
<header> <h1>My Blog</h1> <nav> <a href="/">Home</a> <a href="/about">About</a> <a href="/contact">Contact</a> </nav> </header> <main> <article> <h2>My First Post</h2> <p>Welcome to my blog...</p> </article> </main> <footer> <p>© 2024 My Blog</p> </footer>

6. Forms

Forms collect user input and are essential for interactive websites.

contact-form.html
<form action="/submit" method="post"> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email" required> <label for="message">Message:</label> <textarea id="message" name="message" rows="4"></textarea> <button type="submit">Send Message</button> </form>

Common Input Types

  • text - Single line text
  • email - Email addresses with validation
  • password - Hidden text
  • number - Numeric input
  • checkbox - Multiple selections
  • radio - Single selection from group
  • file - File uploads

7. Images and Media

Images

images.html
<img src="logo.png" alt="Company Logo" width="200"> <figure> <img src="chart.png" alt="Sales data"> <figcaption>Q4 Sales Performance</figcaption> </figure>
Accessibility Tip

Always include alt text for images. It helps screen readers and displays when images fail to load.

8. Best Practices

Code Quality

  • Use semantic HTML elements that describe content meaning
  • Maintain proper indentation for readability
  • Always include alt attributes for images
  • Use meaningful class and id names
  • Validate your HTML code regularly

Performance

  • Optimize image sizes and use appropriate formats
  • Keep HTML structure clean and minimal
  • Use external CSS and JavaScript files
  • Minimize HTTP requests when possible

Accessibility

  • Use proper heading hierarchy (h1, h2, h3...)
  • Label form inputs clearly
  • Ensure keyboard navigation works
  • Provide sufficient color contrast
  • Use ARIA attributes when needed
Next Steps

Once you master HTML, learn CSS for styling and JavaScript for interactivity. These three technologies form the foundation of modern web development.
