1. What is HTML?

Hey there! HTML is like the skeleton of every website you visit. It's the language that tells your web browser "put this text here, make this a heading, add a link there." Think of it as the blueprint for building web pages.

Your First HTML Page

Every HTML page follows the same basic structure. Here's what it looks like:

1 <!DOCTYPE html>
2 <html lang="en">
3 <head>
4 <meta charset="UTF-8" />
5 <meta name="viewport" content="width=device-width, initial-scale=1.0" />
6 <title>Page Title</title>
7 </head>
8 <body>
9 <h1>This is a heading</h1>
10 <p>This is a paragraph.</p>
11 </body>
12 </html>

Quick tip: Save your HTML files with a .html extension (like "my-page.html") and double-click them to open in your web browser. That's how you'll see your work!

2. How HTML Pages Are Built

Let's break down the parts of an HTML page - think of it like building a house:

  • <!DOCTYPE html> - Tells the browser "this is an HTML page"
  • <html> - The main container (like the foundation of a house)
  • <head> - Contains information about your page (like the title that shows in the browser tab)
  • <body> - Contains everything people actually see on your page

The Head Section

The head is like the "behind the scenes" part of your page - it contains important information that doesn't show up on the page itself:

1 <head>
2 <meta charset="UTF-8">
3 <meta name="viewport" content="width=device-width, initial-scale=1.0">
4 <title>My Website</title>
5 <meta name="description" content="A brief description of my website">
6 </head>

3. The Building Blocks - HTML Elements

Headings - Making Text Stand Out

HTML gives you six different heading sizes, just like different text sizes in a document:

1 <h1>Main Heading</h1>
2 <h2>Section Heading</h2>
3 <h3>Subsection Heading</h3>
4 <h4>Minor Heading</h4>
5 <h5>Small Heading</h5>
6 <h6>Smallest Heading</h6>

Paragraphs and Text Formatting

1 <p>This is a regular paragraph.</p>
2 <p>Text can be <strong>bold</strong> or <em>italic</em>.</p>
3 <p>You can also <mark>highlight</mark> text.</p>

Links - Connecting Pages Together

1 <a href="https://example.com">External Link</a>
2 <a href="about.html">Internal Link</a>
3 <a href="mailto:email@example.com">Email Link</a>

Lists - Organizing Information

<!-- Bullet points (unordered list) --> <ul> <li>First item</li> <li>Second item</li> <li>Third item</li> </ul> <!-- Numbered list (ordered list) --> <ol> <li>Step one</li> <li>Step two</li> <li>Step three</li> </ol>

4. Forms - Getting Information from Users

Forms let people interact with your website - like signing up for a newsletter or leaving a comment:

<form action="/submit" method="post"> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email" required> <button type="submit">Submit</button> </form>

Different Types of Input Fields

  • text - A simple text box for names, titles, etc.
  • email - For email addresses (browsers check the format)
  • password - Hides what you type (for passwords)
  • number - Only allows numbers
  • checkbox - Little boxes you can check/uncheck
  • radio - Round buttons where you pick one option
  • file - Lets people upload files from their computer

5. Semantic HTML - Making Your Code Meaningful

Semantic elements give meaning to your content - they tell browsers and screen readers "this is a header" or "this is the main content":

Element Purpose
<header> The top part of your page (like a page header)
<nav> Navigation menu (like the menu bar on a website)
<main> The most important content on your page
<article> A complete piece of content (like a blog post)
<section> A section of your page (like a chapter in a book)
<footer> The bottom part of your page (like a page footer)
<header> <h1>My Website</h1> <nav> <a href="/">Home</a> <a href="/about">About</a> </nav> </header> <main> <article> <h2>Article Title</h2> <p>Article content goes here...</p> </article> </main> <footer> <p>© 2024 My Website</p> </footer>
Why this matters: Using semantic elements helps people with screen readers understand your page better, and it helps search engines like Google understand what your content is about.
