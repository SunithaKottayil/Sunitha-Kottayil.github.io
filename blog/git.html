👋 Getting Started with Git: A Beginner’s Guide

Hello! If you’re curious about Git and want to learn how to use it for your coding projects, you’re in the right place. When I started with programming, Git seemed mysterious, but it quickly became one of my most valuable tools. Here’s how you can get started, step by step.

What is Git?

Git is a tool that helps you keep track of changes to your files. Imagine writing a story and being able to go back to any previous version whenever you want. That’s what Git does for your code! You can also work with friends and never worry about losing your work.

For more details, check out the official Git tutorial.


Git runs locally on your computer, and GitHub stores your projects in the cloud, making collaboration easy.

Step 1: Install Git

  1. Go to git-scm.com and download Git for your computer.
  2. Follow the instructions to install it. The default settings are fine for most beginners.

Step 2: Set Up Your Identity

After installing Git, open your terminal (Command Prompt, Terminal, or Git Bash) and enter these commands. This tells Git who you are, so your work is recognized.

git config --global user.name "Your Name" git config --global user.email "your@email.com"

Step 3: Create Your First Project

Let’s start a new project folder and turn it into a Git repository that tracks changes.

mkdir my-first-git-project cd my-first-git-project git init

You’ll see a message that Git has initialized your folder. Now Git is watching for changes!

Step 4: Add a File and Save Your Work

Make a simple text file and tell Git to track it, then save your changes.

echo "Hello, Git!" > hello.txt git add hello.txt git commit -m "Add hello.txt with a greeting"

What these do:

  • git add tells Git to track the file.
  • git commit saves a snapshot of your work.

Step 5: Check the Status and History

See what’s going on in your project:

git status git log
  • git status shows which files are being tracked or changed.
  • git log lists your past commits so you can review changes over time.

Step 6: Fix Mistakes

Messed up? No worries! Git lets you undo changes and restore files from your last saved version.

git checkout hello.txt

Step 7: Connect to GitHub and Share Your Work

To back up your code online and collaborate, follow these steps:

  1. Create a free account at github.com.
  2. Create a new repository (a "repo") on GitHub and copy its web URL.
  3. Link your local folder to your GitHub repo and push your commits:
git remote add origin [YOUR-REPO-URL] git push -u origin main

Push your work to the cloud & share your project!

Why Use Git?

  • Never lose your work — go back to any previous version easily.
  • Work together with friends without overwriting each other’s work.
  • Build your portfolio and show your projects to the world.

Extra Tips for Beginners

  • Use git status often to see the state of your files.
  • Think of every commit as a "save point" in a video game.
  • Try using branches to work on new features without affecting the main project.

Final Thoughts

That’s it! You’ve just learned the basics of Git in a simple, friendly way. The best way to learn is to practice—try making changes, adding files, and committing your work often.

Git might feel strange at first, but soon it will become second nature. Happy coding!
