🚀 C#: Next Level — From Intermediate to Advanced

You know the basics—variables, loops, classes. Now it's time to unlock C#'s powerful features to write robust, efficient, and professional code. This hands-on guide combines interactive code, real-world explanations, diagrams, and quizzes so you can confidently tackle serious projects!

1. Collections and LINQ

Arrays are just the beginning. In real applications, you'll use advanced collections and LINQ for querying data.

Common Collections:
  • List<T>: Resizable arrays
  • Dictionary<K,V>: Key-value lookup
  • HashSet<T>: Unique-value collections

LINQ lets you filter and transform these collections neatly.

using System; using System.Collections.Generic; using System.Linq; var numbers = new List<int> {1, 2, 3, 4, 5, 6, 7, 8}; var even = numbers.Where(n => n % 2 == 0).ToList(); Console.WriteLine(string.Join(", ", even)); // Output: 2, 4, 6, 8

2. Properties, Encapsulation & Auto-Properties

Properties control access to data. The preferred, modern C# way is auto-properties:

public class User { public string Name { get; set; } // auto-property public int Age { get; private set; } // can set only inside the class // Custom property logic - for validation: private string _email; public string Email { get { return _email; } set { if (!value.Contains("@")) throw new ArgumentException("Invalid email."); _email = value; } } }

3. Inheritance & Polymorphism

Inheritance allows you to build specialized classes from general blueprints; polymorphism makes using different objects through the same interface easy.

public class Animal { public virtual void Speak() { Console.WriteLine("Some generic animal noise"); } } public class Dog : Animal { public override void Speak() { Console.WriteLine("Woof!"); } } Animal pet = new Dog(); pet.Speak(); // Output: Woof!

4. Abstract Classes and Interfaces

Abstract classes force child classes to implement certain members. Interfaces define contracts, not implementation.

// Abstract Class Example public abstract class Shape { public abstract double Area(); } public class Circle : Shape { public double Radius { get; set; } public override double Area() => Math.PI * Radius * Radius; }
// Interface Example public interface IDrive { void Start(); void Stop(); } public class Car : IDrive { public void Start() { Console.WriteLine("Engine started"); } public void Stop() { Console.WriteLine("Stopped"); } }

5. Delegates & Events

Delegates let you reference methods as variables. Events are for notification systems (Windows Forms, etc.).

// A delegate for functions with no parameters and no return type: public delegate void Notify(); public class Process { public event Notify OnDone; public void Run() { Console.WriteLine("Running..."); OnDone?.Invoke(); // fire the event if any listener is attached! } }

Delegates act as customizable function pointers. Events notify when something happens!

6. Generics

Avoid code duplication and support type-safe operations using generics:

public class Box<T> { public T Value; } Box<string> bx = new Box<string>(); bx.Value = "Hello C#";

7. Exception Handling (Advanced)

Master exception types, custom exceptions, and finally.

try { throw new InvalidOperationException("Something went wrong!"); } catch (InvalidOperationException ex) { Console.WriteLine(ex.Message); } finally { Console.WriteLine("Cleanup, even if there was an error!"); }

8. Asynchronous Programming (async/await)

Use async and await for responsive, modern apps (no freezing UI).

using System.Threading.Tasks; public async Task DownloadDataAsync() { Console.WriteLine("Start download"); await Task.Delay(2000); // simulates waiting for download Console.WriteLine("Finished downloading"); }
Tip: await lets your program do other work while waiting, perfect for web/API/database calls.

9. Files, Streams, and Serialization

Real-world applications read/write/move files and serialize/deserialize data.

using System.IO; File.WriteAllText("test.txt", "Hello, file!"); string contents = File.ReadAllText("test.txt"); Console.WriteLine(contents);
using System.Text.Json; public class Person { public string Name {get;set;} } string json = JsonSerializer.Serialize(new Person() { Name = "Sam" }); var person = JsonSerializer.Deserialize<Person>(json); Console.WriteLine(person.Name);

10. Dependency Injection & Design Patterns (Intro)

Professional C# often applies dependency injection for testable, flexible code, and uses famous design patterns (Singleton, Factory, Repository, etc.).

// Example: constructor injection public class Logger { public void Log(string msg) { Console.WriteLine(msg); } } public class Service { private readonly Logger _logger; public Service(Logger logger) { _logger = logger; } public void DoWork() { _logger.Log("Working!"); } } // Usage var logger = new Logger(); var service = new Service(logger); // DI in action!
