🚀 Learning TypeScript

Hey there! TypeScript is like JavaScript with superpowers - it adds extra safety features that help you catch errors before they happen. Think of it as JavaScript wearing a safety helmet! Whether you're new to TypeScript or moving from JavaScript, this guide will help you master TypeScript's powerful features step-by-step with practical examples, helpful diagrams, and fun quizzes.

1. What is TypeScript & Why Use It?

TypeScript is JavaScript with a safety net! It adds static types—this means you can catch errors early and write more reliable code. It's like having a spell-checker for your code that catches mistakes before you even run it.

Key benefits:

  • Helps prevent many common bugs by typing variables and functions.
  • Improves your code editor: better autocomplete, refactoring, and error detection.
  • Great for large projects and teams to maintain code quality.
  • Compatible with existing JavaScript libraries and frameworks.

2. Getting Started with TypeScript

  1. Install Node.js (includes npm).
  2. Open your command line and install TypeScript globally: 
    npm install -g typescript
  3. Create a tsconfig.json to configure your project (optional but recommended): 
    {
  "compilerOptions": {
    "target": "es6",
    "module": "commonjs",
    "strict": true
  }
}
  4. Compile your first file: 
    tsc filename.ts

This generates plain JavaScript you can run in any JavaScript environment.

Quick tip: Use tsc --watch to auto-compile on file changes during development.

3. Basic Types - Your TypeScript Toolbox

TypeScript has several built-in types to declare your variables. Think of types as labels that tell TypeScript what kind of data you're working with:

  • string: Text (like "Hello World")
  • number: All numeric values (integers, decimals)
  • boolean: true or false
  • any: Any kind of value (use sparingly - it's like turning off TypeScript)
  • unknown: Like any, but safer
  • void: For functions returning nothing
  • null and undefined
  • tuple: Fixed-length arrays with typed elements
  • enum: Named constants
// Examples of type annotations
let username: string = "Alice";
let age: number = 28;
let isActive: boolean = true;
let data: any = "Surprise!";

let tupleExample: [string, number];
tupleExample = ["hello", 42];

enum Color { Red, Green, Blue }
let c: Color = Color.Green;

console.log(username, age, isActive, tupleExample, c);

4. Functions - Making Your Code Type-Safe

Functions in TypeScript have typed parameters and return types. This means you can be sure about what goes in and what comes out:

// Function with typed parameters and return value
function add(x: number, y: number): number {
  return x + y;
}

console.log(add(5, 3)); // 8

// Optional and default parameters
function greet(name: string, msg: string = "Hello"): void {
  console.log(`${msg}, ${name}!`);
}

greet("Alice");      // Hello, Alice!
greet("Bob", "Hi");  // Hi, Bob

5. Interfaces & Types - Defining Object Shapes

Define object shapes for better type safety. Think of interfaces as blueprints that describe what an object should look like:

// Interface example
interface Person {
  name: string;
  age?: number;  // optional
}

function printPerson(p: Person) {
  console.log(`Name: ${p.name}`);
  if (p.age) console.log(`Age: ${p.age}`);
}

printPerson({ name: "Alice", age: 30 });
printPerson({ name: "Bob" });

Type aliases provide similar functionality with some additional flexibility:

type Animal = {
  species: string;
  age: number;
};

const dog: Animal = { species: "Dog", age: 5 };
console.log(dog);

6. Classes & Object-Oriented Programming

TypeScript supports classes with strong typing, access modifiers, and more. It's like building with LEGO blocks - you can create complex structures from simple pieces:

class Vehicle {
  protected brand: string;

  constructor(brand: string) {
    this.brand = brand;
  }

  public honk(): void {
    console.log(`${this.brand} goes beep beep!`);
  }
}

class Car extends Vehicle {
  private model: string;

  constructor(brand: string, model: string) {
    super(brand);
    this.model = model;
  }

  public showModel(): void {
    console.log(`Model: ${this.model}`);
  }
}

const myCar = new Car("Toyota", "Corolla");
myCar.honk();          // Toyota goes beep beep!
myCar.showModel();     // Model: Corolla

7. Advanced Types - TypeScript's Superpowers

  • Union Types: variables that can hold multiple types (like a Swiss Army knife).
  • Intersection Types: combine multiple types into one (like mixing colors).
  • Type Guards: check types at runtime to narrow type (like detective work).
  • Literal Types: restrict variable to exact values (like a strict teacher).
  • Mapped Types and Conditional Types (advanced utility types).
// Union type example
function printId(id: number | string) {
  if (typeof id === "string") {
    console.log(`ID (string): ${id.toUpperCase()}`);
  } else {
    console.log(`ID (number): ${id}`);
  }
}

printId("abc123");
printId(101);

8. Generics - Reusable Type Templates

Write reusable and type-safe functions/classes. Think of generics as templates that work with any type you give them:

function identity(arg: T): T {
  return arg;
}

let output1 = identity("my String");
let output2 = identity(100);

console.log(output1, output2);

class Box {
  contents: T;
  constructor(value: T) {
    this.contents = value;
  }
}

const box = new Box(42);
console.log(box.contents);

9. Modules & Namespaces - Organizing Your Code

Organize code into separate files and namespaces for modularity. It's like organizing your closet - everything has its place:

  • export and import to share code across files.
  • Namespaces group related code internally.
// math.ts
export function add(x: number, y: number): number {
  return x + y;
}

// app.ts
import { add } from './math';

console.log(add(2, 3));

10. Async Programming - Handling Time-Based Operations

Handle asynchronous code gracefully with promises and async/await. This is like managing multiple tasks at once:

// Promise example
function wait(ms: number): Promise {
  return new Promise(resolve => setTimeout(resolve, ms));
}

wait(1000).then(() => console.log("Waited 1 second"));

// Async/await example
async function asyncCall() {
  console.log("Start");
  await wait(1500);
  console.log("End");
}

asyncCall();

11. Exception Handling - Dealing with Errors Gracefully

try {
  throw new Error("Oops!");
} catch (error) {
  console.error("Caught error:", error.message);
} finally {
  console.log("Cleanup code always runs.");
}

12. Decorators - Adding Extra Functionality

Decorators are special annotations for classes and methods (enable with compiler options). Think of them as stickers you put on your code to add extra features:

// Simple class decorator example
function sealed(constructor: Function) {
  Object.seal(constructor);
  Object.seal(constructor.prototype);
}

@sealed
class Greeter {
  greeting: string;
  constructor(message: string) {
    this.greeting = message;
  }
  greet() {
    return "Hello, " + this.greeting;
  }
}

13. Best Practices & Tips for Success

  • Always enable strict mode in tsconfig.json for better type safety.
  • Use interfaces for large or complex object shapes.
  • Prefer const and let over var.
  • Write small, reusable functions with clear types.
  • Use type aliases and utility types to reduce duplication.
  • Keep your code organized with modules and namespaces.
  • Practice with small projects and explore DefinitelyTyped for types of third-party libraries.
