7. Arrays and Collections

Arrays and collections allow you to store multiple values in a single variable. This is essential for working with lists of data.

Arrays

Arrays store multiple values of the same type in a fixed-size sequential collection:

using System; class Program { static void Main() { // Declare and initialize arrays int[] numbers = {1, 2, 3, 4, 5}; string[] names = {"Alice", "Bob", "Charlie", "Diana"}; // Access array elements using index (starts at 0) Console.WriteLine($"First number: {numbers[0]}"); Console.WriteLine($"Last name: {names[names.Length - 1]}"); // Loop through arrays Console.WriteLine("\nAll numbers:"); for (int i = 0; i < numbers.Length; i++) { Console.WriteLine($"Index {i}: {numbers[i]}"); } Console.WriteLine("\nAll names:"); foreach (string name in names) { Console.WriteLine($"Hello, {name}!"); } // Modify array elements numbers[0] = 10; Console.WriteLine($"Modified first number: {numbers[0]}"); } }

Lists (Dynamic Arrays)

Lists are dynamic collections that can grow and shrink at runtime:

using System; using System.Collections.Generic; class Program { static void Main() { // Create a List List fruits = new List(); // Add items fruits.Add("Apple"); fruits.Add("Banana"); fruits.Add("Orange"); Console.WriteLine($"We have {fruits.Count} fruits"); // Insert at specific position fruits.Insert(1, "Mango"); // Remove items fruits.Remove("Banana"); // Check if item exists if (fruits.Contains("Apple")) { Console.WriteLine("We have apples!"); } // Loop through List Console.WriteLine("\nOur fruits:"); foreach (string fruit in fruits) { Console.WriteLine($"- {fruit}"); } // Convert to array if needed string[] fruitArray = fruits.ToArray(); } }
Array vs List
  • Arrays - Fixed size, faster access, less memory overhead
  • Lists - Dynamic size, can add/remove items, more flexible
  • Use arrays when size is known and won't change
  • Use Lists when you need to add/remove items dynamically

8. Exception Handling

Exception handling helps your program deal with errors gracefully instead of crashing. Use try-catch blocks to handle potential errors:

using System; class Program { static void Main() { // Basic exception handling try { Console.Write("Enter a number: "); string input = Console.ReadLine(); int number = int.Parse(input); Console.Write("Enter another number to divide by: "); string input2 = Console.ReadLine(); int divisor = int.Parse(input2); int result = number / divisor; Console.WriteLine($"Result: {number} / {divisor} = {result}"); } catch (FormatException) { Console.WriteLine("Error: Please enter a valid number!"); } catch (DivideByZeroException) { Console.WriteLine("Error: Cannot divide by zero!"); } catch (Exception ex) { Console.WriteLine($"An unexpected error occurred: {ex.Message}"); } finally { Console.WriteLine("Program execution completed."); } // Better approach with validation ValidatedDivision(); } static void ValidatedDivision() { Console.WriteLine("\n--- Safe Division ---"); try { int num1 = GetValidNumber("Enter first number: "); int num2 = GetValidNumber("Enter second number: "); if (num2 == 0) { throw new ArgumentException("Division by zero is not allowed!"); } double result = (double)num1 / num2; Console.WriteLine($"Result: {num1} / {num2} = {result:F2}"); } catch (ArgumentException ex) { Console.WriteLine($"Input Error: {ex.Message}"); } } static int GetValidNumber(string prompt) { while (true) { try { Console.Write(prompt); return int.Parse(Console.ReadLine()); } catch (FormatException) { Console.WriteLine("Invalid input! Please enter a number."); } } } }
Common Exception Types
  • FormatException - Invalid string format (e.g., parsing "abc" as number)
  • ArgumentException - Invalid argument passed to method
  • IndexOutOfRangeException - Array/list index out of bounds
  • NullReferenceException - Trying to use null object
  • FileNotFoundException - File doesn't exist
  • DivideByZeroException - Division by zero

9. Advanced Object-Oriented Programming

Inheritance

Inheritance allows a class to inherit properties and methods from another class, promoting code reuse:

using System; // Base class (parent) class Animal { public string Name { get; set; } public int Age { get; set; } public Animal(string name, int age) { Name = name; Age = age; } public virtual void MakeSound() { Console.WriteLine($"{Name} makes a sound"); } public void Sleep() { Console.WriteLine($"{Name} is sleeping"); } } // Derived class (child) class Dog : Animal { public string Breed { get; set; } public Dog(string name, int age, string breed) : base(name, age) { Breed = breed; } // Override parent method public override void MakeSound() { Console.WriteLine($"{Name} barks: Woof! Woof!"); } // Dog-specific method public void Fetch() { Console.WriteLine($"{Name} is fetching the ball!"); } } class Cat : Animal { public Cat(string name, int age) : base(name, age) { } public override void MakeSound() { Console.WriteLine($"{Name} meows: Meow! Meow!"); } public void Scratch() { Console.WriteLine($"{Name} is scratching the furniture!"); } } class Program { static void Main() { // Create instances Dog myDog = new Dog("Buddy", 3, "Golden Retriever"); Cat myCat = new Cat("Whiskers", 2); // Use inherited properties and methods Console.WriteLine($"Dog: {myDog.Name}, Age: {myDog.Age}, Breed: {myDog.Breed}"); myDog.MakeSound(); // Calls overridden method myDog.Fetch(); // Dog-specific method myDog.Sleep(); // Inherited method Console.WriteLine(); Console.WriteLine($"Cat: {myCat.Name}, Age: {myCat.Age}"); myCat.MakeSound(); // Calls overridden method myCat.Scratch(); // Cat-specific method myCat.Sleep(); // Inherited method // Polymorphism in action Console.WriteLine("\n--- Polymorphism ---"); Animal[] animals = {myDog, myCat}; foreach (Animal animal in animals) { animal.MakeSound(); // Calls appropriate overridden method } } }

Encapsulation and Access Modifiers

Encapsulation protects data by controlling access through properties and methods:

using System; class BankAccount { // Private fields (encapsulated data) private string accountNumber; private decimal balance; private string ownerName; // Public properties with validation public string AccountNumber { get { return accountNumber; } private set { accountNumber = value; } // Only class can set this } public decimal Balance { get { return balance; } private set { if (value < 0) throw new ArgumentException("Balance cannot be negative!"); balance = value; } } public string OwnerName { get { return ownerName; } set { if (string.IsNullOrWhiteSpace(value)) throw new ArgumentException("Owner name cannot be empty!"); ownerName = value; } } // Constructor public BankAccount(string accountNumber, string ownerName, decimal initialBalance = 0) { AccountNumber = accountNumber; OwnerName = ownerName; Balance = initialBalance; } // Public methods for controlled access public void Deposit(decimal amount) { if (amount <= 0) { throw new ArgumentException("Deposit amount must be positive!"); } Balance += amount; Console.WriteLine($"Deposited ${amount:F2}. New balance: ${Balance:F2}"); } public bool Withdraw(decimal amount) { if (amount <= 0) { Console.WriteLine("Withdrawal amount must be positive!"); return false; } if (amount > Balance) { Console.WriteLine("Insufficient funds!"); return false; } Balance -= amount; Console.WriteLine($"Withdrew ${amount:F2}. New balance: ${Balance:F2}"); return true; } public void DisplayAccountInfo() { Console.WriteLine($"Account: {AccountNumber}"); Console.WriteLine($"Owner: {OwnerName}"); Console.WriteLine($"Balance: ${Balance:F2}"); } } class Program { static void Main() { try { BankAccount account = new BankAccount("ACC001", "John Doe", 1000.00m); account.DisplayAccountInfo(); Console.WriteLine(); account.Deposit(500.00m); account.Withdraw(200.00m); account.Withdraw(2000.00m); // Should fail Console.WriteLine(); account.DisplayAccountInfo(); // This would cause compilation error (private setter): // account.Balance = -100; // Cannot access private setter } catch (ArgumentException ex) { Console.WriteLine($"Error: {ex.Message}"); } } }
Access Modifiers
  • public - Accessible from anywhere
  • private - Only accessible within the same class
  • protected - Accessible within class and derived classes
  • internal - Accessible within the same assembly

10. Enums and Structs

Enums (Enumerations)

Enums define a set of named constants, making code more readable and maintainable:

using System; // Define enums enum DayOfWeek { Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday } enum OrderStatus { Pending = 1, Processing = 2, Shipped = 3, Delivered = 4, Cancelled = 5 } class Order { public int OrderId { get; set; } public string CustomerName { get; set; } public OrderStatus Status { get; set; } public DateTime OrderDate { get; set; } public Order(int orderId, string customerName) { OrderId = orderId; CustomerName = customerName; Status = OrderStatus.Pending; OrderDate = DateTime.Now; } public void UpdateStatus(OrderStatus newStatus) { Status = newStatus; Console.WriteLine($"Order {OrderId} status updated to: {Status}"); } public void DisplayOrder() { Console.WriteLine($"Order ID: {OrderId}"); Console.WriteLine($"Customer: {CustomerName}"); Console.WriteLine($"Status: {Status} ({(int)Status})"); Console.WriteLine($"Order Date: {OrderDate:yyyy-MM-dd HH:mm}"); } } class Program { static void Main() { // Using enums DayOfWeek today = DayOfWeek.Friday; Console.WriteLine($"Today is {today}"); if (today == DayOfWeek.Friday || today == DayOfWeek.Saturday || today == DayOfWeek.Sunday) { Console.WriteLine("It's weekend time!"); } Console.WriteLine(); // Order example Order order = new Order(1001, "Alice Johnson"); order.DisplayOrder(); Console.WriteLine(); order.UpdateStatus(OrderStatus.Processing); order.UpdateStatus(OrderStatus.Shipped); order.UpdateStatus(OrderStatus.Delivered); Console.WriteLine(); order.DisplayOrder(); // Convert enum to string and back string statusString = OrderStatus.Shipped.ToString(); OrderStatus parsedStatus = (OrderStatus)Enum.Parse(typeof(OrderStatus), statusString); Console.WriteLine($"Parsed status: {parsedStatus}"); } }

Structs

Structs are value types that can contain data and methods, useful for small, simple data structures:

using System; // Define a struct struct Point { public int X { get; set; } public int Y { get; set; } public Point(int x, int y) { X = x; Y = y; } public double DistanceFromOrigin() { return Math.Sqrt(X * X + Y * Y); } public double DistanceTo(Point other) { int deltaX = X - other.X; int deltaY = Y - other.Y; return Math.Sqrt(deltaX * deltaX + deltaY * deltaY); } public override string ToString() { return $"({X}, {Y})"; } } struct Rectangle { public Point TopLeft { get; set; } public Point BottomRight { get; set; } public Rectangle(Point topLeft, Point bottomRight) { TopLeft = topLeft; BottomRight = bottomRight; } public int Width => BottomRight.X - TopLeft.X; public int Height => BottomRight.Y - TopLeft.Y; public int Area => Width * Height; public bool Contains(Point point) { return point.X >= TopLeft.X && point.X <= BottomRight.X && point.Y >= TopLeft.Y && point.Y <= BottomRight.Y; } } class Program { static void Main() { // Create points Point p1 = new Point(3, 4); Point p2 = new Point(6, 8); Point origin = new Point(0, 0); Console.WriteLine($"Point 1: {p1}"); Console.WriteLine($"Point 2: {p2}"); Console.WriteLine($"Origin: {origin}"); Console.WriteLine($"Distance from p1 to origin: {p1.DistanceFromOrigin():F2}"); Console.WriteLine($"Distance from p1 to p2: {p1.DistanceTo(p2):F2}"); // Create rectangle Rectangle rect = new Rectangle(new Point(0, 0), new Point(10, 5)); Console.WriteLine($"\nRectangle: {rect.TopLeft} to {rect.BottomRight}"); Console.WriteLine($"Width: {rect.Width}, Height: {rect.Height}"); Console.WriteLine($"Area: {rect.Area}"); Point testPoint = new Point(5, 3); Console.WriteLine($"Does rectangle contain {testPoint}? {rect.Contains(testPoint)}"); } }
Struct vs Class
  • Structs - Value types, stored on stack, copied by value
  • Classes - Reference types, stored on heap, copied by reference
  • Use structs for small, simple data without inheritance needs
  • Use classes for complex objects that may need inheritance

1. Getting Started - Your First Program

Every C# program starts with a Main method. This is where your code begins execution. Let's look at the classic "Hello World" example:

using System; class Program { static void Main() { Console.WriteLine("Hello, World!"); Console.WriteLine("Welcome to C# programming!"); } }
Understanding the Code
  • using System; - Imports the System namespace for basic functionality
  • class Program - Defines a class named Program
  • static void Main() - The entry point of your application
  • Console.WriteLine() - Outputs text to the console

2. Variables and Data Types

Variables are containers that store data. C# has several built-in data types, each designed for specific kinds of information:

Common Data Types

  • int - Whole numbers (-2,147,483,648 to 2,147,483,647)
  • double - Decimal numbers with high precision
  • string - Text data (sequences of characters)
  • bool - True or false values
  • char - Single characters
using System; class Program { static void Main() { // Different data types int age = 25; double price = 19.99; string name = "Sarah Johnson"; bool isStudent = true; char grade = 'A'; // Display the values Console.WriteLine($"Name: {name}"); Console.WriteLine($"Age: {age}"); Console.WriteLine($"Price: ${price}"); Console.WriteLine($"Is Student: {isStudent}"); Console.WriteLine($"Grade: {grade}"); } }
String Interpolation

Notice the $ before the string and the {} brackets. This is called string interpolation, a clean way to include variables inside strings.

3. User Input and Output

Interactive programs need to get input from users and display results. C# provides simple methods for console input and output:

using System; class Program { static void Main() { // Get user input Console.Write("Enter your name: "); string userName = Console.ReadLine(); Console.Write("Enter your favorite number: "); string numberInput = Console.ReadLine(); int favoriteNumber = int.Parse(numberInput); // Process and display results int doubledNumber = favoriteNumber * 2; Console.WriteLine($"\nHello, {userName}!"); Console.WriteLine($"Your favorite number is {favoriteNumber}"); Console.WriteLine($"Double that number is {doubledNumber}"); } }
Input Conversion

Console.ReadLine() always returns a string. Use int.Parse() or Convert.ToInt32() to convert strings to numbers.

4. Making Decisions with if/else

Programs often need to make decisions based on different conditions. The if/else statement allows your program to choose different paths:

using System; class Program { static void Main() { Console.Write("Enter your age: "); int age = int.Parse(Console.ReadLine()); if (age >= 18) { Console.WriteLine("You are an adult."); if (age >= 65) { Console.WriteLine("You qualify for senior discounts!"); } } else if (age >= 13) { Console.WriteLine("You are a teenager."); } else { Console.WriteLine("You are a child."); } // Multiple conditions if (age >= 16 && age < 18) { Console.WriteLine("You can drive but can't vote yet."); } } }
Common Comparison Operators
  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to
  • && Logical AND
  • || Logical OR

5. Loops - Repeating Actions

Loops allow you to repeat code multiple times. This is essential for processing lists of data, creating menus, or performing repetitive tasks.

For Loops

Use when you know how many times you want to repeat something:

using System; class Program { static void Main() { // Count from 1 to 10 for (int i = 1; i <= 10; i++) { Console.WriteLine($"Count: {i}"); } // Calculate factorial Console.Write("\nEnter a number for factorial: "); int number = int.Parse(Console.ReadLine()); int factorial = 1; for (int i = 1; i <= number; i++) { factorial *= i; } Console.WriteLine($"Factorial of {number} is {factorial}"); } }

While Loops

Use when you want to repeat until a condition changes:

using System; class Program { static void Main() { int attempts = 0; string password = ""; while (password != "secret123") { attempts++; Console.Write($"Attempt {attempts} - Enter password: "); password = Console.ReadLine(); if (password != "secret123") { Console.WriteLine("Incorrect password. 6. Methods - Organizing Your Code

Methods (also called functions) help you organize code into reusable pieces. Instead of writing the same code multiple times, you can create a method and call it whenever needed.

using System; class Program { // Method to calculate area of a rectangle static double CalculateRectangleArea(double length, double width) { return length * width; } // Method to greet a user static void GreetUser(string name, int age) { Console.WriteLine($"Hello, {name}!"); Console.WriteLine($"I see you are {age} years old."); } // Method to check if a number is even static bool IsEven(int number) { return number % 2 == 0; } static void Main() { // Using our methods double area = CalculateRectangleArea(5.0, 3.0); Console.WriteLine($"Rectangle area: {area}"); GreetUser("Alice", 28); int testNumber = 7; if (IsEven(testNumber)) { Console.WriteLine($"{testNumber} is even"); } else { Console.WriteLine($"{testNumber} is odd"); } } }
Method Components
  • static - Can be called without creating an object
  • void - Returns nothing; other methods specify return type
  • Parameters - Input values the method needs
  • return - Sends a value back to the caller

7. Introduction to Classes and Objects

Object-Oriented Programming (OOP) is a fundamental concept in C#. Classes are blueprints for creating objects, which combine data (properties) and behavior (methods).

using System; // Define a class for representing a car class Car { // Properties (data) public string Make { get; set; } public string Model { get; set; } public int Year { get; set; } public double Mileage { get; set; } // Constructor (runs when creating a new car) public Car(string make, string model, int year) { Make = make; Model = model; Year = year; Mileage = 0; } // Methods (behavior) public void Drive(double miles) { Mileage += miles; Console.WriteLine($"Drove {miles} miles. Key OOP Concepts
  • Class - A blueprint that defines properties and methods
