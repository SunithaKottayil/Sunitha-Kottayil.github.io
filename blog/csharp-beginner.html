1. Your First C# Program - Hello World!

Every programming journey starts with a simple program that displays "Hello, World!" on the screen. This tradition helps you verify that your development environment is working and gives you a feel for the language's basic structure.

Let's look at the most basic C# program. Don't worry about understanding every detail right now - we'll explain each part as we go through the guide.

using System; class Program { static void Main() { Console.WriteLine("Hello, World!"); Console.WriteLine("Welcome to C# programming!"); } }
🔍 Breaking Down the Code
  • using System; - This tells C# we want to use built-in features like Console.WriteLine
  • class Program - Creates a container called "Program" to hold our code
  • static void Main() - This is where your program starts running (the entry point)
  • Console.WriteLine() - Displays text on the screen
  • { } - Curly braces group related code together
💡 Try This!

Copy this code into a C# development environment (like Visual Studio or an online compiler) and run it. You should see "Hello, World!" and "Welcome to C# programming!" displayed on the screen.

2. Variables and Data Types - Storing Information

Variables are like labeled boxes where you can store different types of information. Just like you might have separate boxes for books, clothes, and toys, C# has different data types for different kinds of information.

The Most Common Data Types

  • int - Whole numbers like 42, -10, or 0
  • double - Numbers with decimal points like 3.14, -2.5, or 100.0
  • string - Text like "Hello", "John Smith", or "Programming is fun!"
  • bool - True or false values (yes/no, on/off)
  • char - Single characters like 'A', '5', or '!'

Here's how to create and use variables in C#:

using System; class Program { static void Main() { // Creating variables and giving them values int age = 25; double price = 19.99; string name = "Sarah Johnson"; bool isStudent = true; char grade = 'A'; // Displaying the values on screen Console.WriteLine($"Name: {name}"); Console.WriteLine($"Age: {age}"); Console.WriteLine($"Price: ${price}"); Console.WriteLine($"Is Student: {isStudent}"); Console.WriteLine($"Grade: {grade}"); // You can change variable values age = 26; Console.WriteLine($"New age: {age}"); } }
🎯 String Interpolation Magic

Notice the $ symbol before the quotes and the {} brackets around variable names? This is called string interpolation - it's a neat way to insert variable values directly into text. Much cleaner than older methods!

🎯 Practice Exercise

Try creating variables for your own information:

Then display them all using Console.WriteLine with string interpolation!

3. Getting Input from Users

Real programs need to interact with users. Instead of just displaying information, we want to ask users questions and respond to their answers. This makes our programs dynamic and useful!

C# provides simple methods to get input from users and display output:

using System; class Program { static void Main() { // Ask the user for their name Console.Write("What's your name? "); string userName = Console.ReadLine(); // Ask for their favorite number Console.Write("What's your favorite number? "); string numberInput = Console.ReadLine(); int favoriteNumber = int.Parse(numberInput); // Do something fun with the number int doubledNumber = favoriteNumber * 2; // Show personalized results Console.WriteLine($"\nHello, {userName}! Nice to meet you!"); Console.WriteLine($"Your favorite number is {favoriteNumber}"); Console.WriteLine($"Did you know that {favoriteNumber} × 2 = {doubledNumber}?"); Console.WriteLine($"That's pretty cool, {userName}!"); } }
⚠️ Important Note About Input

Console.ReadLine() always gives you text (a string), even if the user types a number. When you need a number for calculations, you must convert it using int.Parse() for whole numbers or double.Parse() for decimals.

💡 The Difference
  • Console.Write() - Displays text and keeps the cursor on the same line
  • Console.WriteLine() - Displays text and moves to the next line

4. Making Decisions with if/else

Programs become really powerful when they can make decisions. Just like you decide what to wear based on the weather, programs can choose what to do based on different conditions. This is where if/else statements shine!

Let's create a program that gives different responses based on a person's age:

using System; class Program { static void Main() { Console.Write("Please enter your age: "); int age = int.Parse(Console.ReadLine()); if (age >= 18) { Console.WriteLine("You're an adult! 🎉"); if (age >= 65) { Console.WriteLine("You qualify for senior discounts!"); } else if (age >= 21) { Console.WriteLine("You can legally drink in the US!"); } } else if (age >= 13) { Console.WriteLine("You're a teenager! 😎"); Console.WriteLine("High school years can be exciting!"); } else { Console.WriteLine("You're still a kid! 🧒"); Console.WriteLine("Enjoy your childhood - it's special!"); } // Multiple conditions with AND (&&) and OR (||) if (age >= 16 && age < 18) { Console.WriteLine("You can drive but can't vote yet in most places."); } if (age == 13 || age == 18 || age == 21) { Console.WriteLine("This is a milestone birthday! 🎂"); } } }
🔧 Comparison Operators You'll Use
  • == - Equal to (Is this exactly the same?)
  • != - Not equal to (Is this different?)
  • > - Greater than
  • < - Less than
  • >= - Greater than or equal to
  • <= - Less than or equal to
  • && - AND (both conditions must be true)
  • || - OR (at least one condition must be true)

5. Loops - Repeating Actions Efficiently

Imagine having to write "I will not talk in class" 100 times by hand - that would be tedious! Loops let computers do repetitive tasks quickly and efficiently. They're one of the most powerful features in programming.

For Loops - When You Know How Many Times

Use for loops when you know exactly how many times you want to repeat something:

using System; class Program { static void Main() { // Count from 1 to 10 Console.WriteLine("Counting from 1 to 10:"); for (int i = 1; i <= 10; i++) { Console.WriteLine($"Count: {i}"); } // Let's calculate a factorial (1 × 2 × 3 × ... × n) Console.Write("\nEnter a number to calculate its factorial: "); int number = int.Parse(Console.ReadLine()); int factorial = 1; for (int i = 1; i <= number; i++) { factorial = factorial * i; // Can also write: factorial *= i; } Console.WriteLine($"The factorial of {number} is {factorial}"); // Create a simple times table Console.WriteLine($"\nTimes table for {number}:"); for (int i = 1; i <= 10; i++) { Console.WriteLine($"{number} × {i} = {number * i}"); } } }

While Loops - When You Don't Know How Many Times

Use while loops when you want to keep doing something until a certain condition changes:

using System; class Program { static void Main() { // Password guessing game string correctPassword = "secret123"; string userPassword = ""; int attempts = 0; Console.WriteLine("🔐 Password Protected System"); Console.WriteLine("(Hint: The password is 'secret123')"); while (userPassword != correctPassword) { attempts++; Console.Write($"Attempt {attempts} - Enter password: "); userPassword = Console.ReadLine(); if (userPassword != correctPassword) { Console.WriteLine("❌ Incorrect! Try again..."); } } Console.WriteLine($"✅ Access granted! It took you {attempts} attempts."); // Number guessing game Random random = new Random(); int secretNumber = random.Next(1, 11); // Random number 1-10 int guess = 0; Console.WriteLine("\n🎯 Guess my number (between 1 and 10):"); while (guess != secretNumber) { Console.Write("Your guess: "); guess = int.Parse(Console.ReadLine()); if (guess < secretNumber) { Console.WriteLine("Too low! Try higher."); } else if (guess > secretNumber) { Console.WriteLine("Too high! Try lower."); } else { Console.WriteLine("🎉 Congratulations! You got it!"); } } } }
🎯 Loop Tips for Beginners
  • For loops are great for counting and when you know the exact number of repetitions
  • While loops are perfect for "keep doing this until something happens" situations
  • Always make sure your loop will eventually stop (avoid infinite loops!)
  • The variable i in for loops is just a convention - you can name it anything

6. Methods - Organizing Your Code

As your programs get bigger, you'll want to organize your code into smaller, manageable pieces. Methods (also called functions) are like mini-programs that do specific tasks. Think of them as recipes - once you write a recipe, you can use it over and over!

Here's how to create and use methods in C#:
