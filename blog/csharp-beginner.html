Chapter 1: Your First Program

Every programmer starts with "Hello, World!" - it's like saying "Hello" when you learn a new language. This simple program will help you make sure everything is working and give you a feel for how C# looks.

Here's the most basic C# program you can write. Don't stress about understanding everything right now - we'll break it down piece by piece.

using System; class Program { static void Main() { Console.WriteLine("Hello, World!"); Console.WriteLine("Welcome to C# programming!"); } }
What each line does
  • using System; - This gives us access to basic stuff like printing to the screen
  • class Program - Think of this as a container that holds our code
  • static void Main() - This is where our program starts running (like the main door)
  • Console.WriteLine() - This prints text to the screen
  • { } - These curly braces group our code together (like putting stuff in a box)
Give it a try!

Copy this code into Visual Studio, Visual Studio Code, or just use an online C# compiler. Run it and you should see "Hello, World!" on your screen. Try changing the text inside the quotes to say something else!

Chapter 2: Variables - Storing Information

Variables are like boxes where you store information. Just like you have different types of boxes for different things (a shoebox for shoes, a toolbox for tools), C# has different types for different kinds of data.

Basic Data Types

  • int - Whole numbers like 42, -10, or 0 (pretty much any whole number you can think of)
  • double - Decimal numbers like 3.14, -2.5, or 100.0 (numbers with decimal points)
  • string - Text like "Hello", "John Smith", or "C# is pretty cool!"
  • bool - True or false values (like yes/no, on/off)
  • char - Single characters like 'A', '5', or '!' (just one letter or symbol)

Here's how to create and use variables in C#:

using System; class Program { static void Main() { // Creating variables with initial values int age = 25; double height = 5.9; string name = "Sarah Johnson"; bool isStudent = true; char grade = 'A'; // Displaying values using string interpolation Console.WriteLine($"Name: {name}"); Console.WriteLine($"Age: {age} years old"); Console.WriteLine($"Height: {height} feet"); Console.WriteLine($"Is student: {isStudent}"); Console.WriteLine($"Grade: {grade}"); // Variables can be changed age = age + 1; // Birthday! Console.WriteLine($"After birthday: {age} years old"); // Basic arithmetic int a = 10; int b = 3; Console.WriteLine($"{a} + {b} = {a + b}"); Console.WriteLine($"{a} - {b} = {a - b}"); Console.WriteLine($"{a} × {b} = {a * b}"); Console.WriteLine($"{a} ÷ {b} = {a / b}"); } }
✨ String Interpolation

The $ before a string and {} brackets create "string interpolation" - a clean way to insert variable values into text. It's much more readable than older concatenation methods!

Chapter 3: Interactive Programs - Getting User Input

Static programs that just display information are useful, but interactive programs that respond to user input are where the real magic happens. Let's learn how to create programs that can have conversations with users!
using System; class Program { static void Main() { // Create a personalized greeting program Console.WriteLine("=== Personal Information Collector ==="); // Get user's name Console.Write("What's your name? "); string userName = Console.ReadLine(); // Get user's age (with conversion) Console.Write("How old are you? "); string ageInput = Console.ReadLine(); int userAge = int.Parse(ageInput); // Get favorite number Console.Write("What's your favorite number? "); double favoriteNumber = double.Parse(Console.ReadLine()); // Process and display personalized information int nextYearAge = userAge + 1; double doubledFavorite = favoriteNumber * 2; double squaredFavorite = favoriteNumber * favoriteNumber; // Create a personalized report Console.WriteLine($"\n========== Personal Report =========="); Console.WriteLine($"Hello, {userName}!"); Console.WriteLine($"You are currently {userAge} years old"); Console.WriteLine($"Next year you'll be {nextYearAge} years old"); Console.WriteLine($"Your favorite number {favoriteNumber} doubled is {doubledFavorite}"); Console.WriteLine($"Your favorite number squared is {squaredFavorite}"); Console.WriteLine($"\nThanks for using our program, {userName}!"); } }
Important: Data Type Conversion

Console.ReadLine() always returns a string, even if the user types numbers. When you need to perform calculations, you must convert the string to the appropriate number type using int.Parse() or double.Parse().

Chapter 4: Making Your Program Think

Now we're getting to the fun part! Programs become really useful when they can make decisions. Think of it like teaching your computer to think - if this happens, do that; if something else happens, do something different.

If Statements - Teaching Your Program to Decide

If statements let your program do different things based on what's happening. It's like a traffic light - if it's green, you go; if it's red, you stop. Simple, right?

using System; class Program { static void Main() { // Simple if statement int temperature = 75; if (temperature > 70) { Console.WriteLine("It's warm outside!"); } // If-else statement int age = 17; if (age >= 18) { Console.WriteLine("You are an adult!"); } else { Console.WriteLine("You are a minor!"); Console.WriteLine($"You'll be an adult in {18 - age} years!"); } // If-else if-else chain int score = 85; if (score >= 90) { Console.WriteLine("Grade: A - Excellent!"); } else if (score >= 80) { Console.WriteLine("Grade: B - Good job!"); } else if (score >= 70) { Console.WriteLine("Grade: C - Satisfactory!"); } else if (score >= 60) { Console.WriteLine("Grade: D - Needs improvement!"); } else { Console.WriteLine("Grade: F - Failed!"); } } }
Comparison Operators
  • == - Equal to (like asking "is this the same as that?")
  • != - Not equal to (like asking "is this different from that?")
  • > - Greater than (like asking "is this bigger than that?")
  • < - Less than (like asking "is this smaller than that?")
  • >= - Greater than or equal to (like asking "is this bigger or the same?")
  • <= - Less than or equal to (like asking "is this smaller or the same?")

Logical Operators - Checking Multiple Things

Sometimes you need to check more than one thing at once. Like "am I old enough AND do I have money?" Logical operators help you combine these checks.

using System; class Program { static void Main() { int age = 25; bool hasLicense = true; bool hasInsurance = false; // AND operator (&&) - both conditions must be true if (age >= 18 && hasLicense) { Console.WriteLine("You can drive! 🚗"); } else { Console.WriteLine("You cannot drive! 🚫"); } // OR operator (||) - at least one condition must be true if (hasLicense || hasInsurance) { Console.WriteLine("You have some form of driving documentation! 📄"); } // NOT operator (!) - reverses the condition if (!hasInsurance) { Console.WriteLine("Warning: You don't have insurance!"); } // Complex condition with parentheses for clarity bool isWeekend = true; bool isHoliday = false; bool isRaining = true; if ((isWeekend || isHoliday) && !isRaining) { Console.WriteLine("Perfect day for outdoor activities!"); } else { Console.WriteLine("Maybe stay inside today! 🏠"); } } }
Some tips
  • Use parentheses to group things together - it makes it clearer what you're checking
  • Keep your conditions simple - if it's getting complicated, break it down
  • Use good variable names - "isOldEnough" is better than "x"
  • Don't nest too many if statements - it gets confusing fast!

Chapter 5: Loops - Doing Things Over and Over

Loops are super useful - they let you repeat actions without writing the same code over and over. Think of it like a washing machine - it keeps doing the same thing until the clothes are clean.

For Loop - When You Know How Many Times

Use a for loop when you know exactly how many times you want to do something. Like counting from 1 to 10, or printing "Hello" 5 times.

using System; class Program { static void Main() { // Basic for loop - count from 1 to 5 Console.WriteLine("Counting from 1 to 5:"); for (int i = 1; i <= 5; i++) { Console.WriteLine($"Number: {i}"); } // Count backwards from 10 to 1 Console.WriteLine("\nCountdown from 10:"); for (int countdown = 10; countdown >= 1; countdown--) { Console.WriteLine($"{countdown}..."); } Console.WriteLine("Blast off!"); // Skip by 2s (even numbers) Console.WriteLine("\nEven numbers from 2 to 10:"); for (int even = 2; even <= 10; even += 2) { Console.WriteLine($"{even}"); } // Calculate sum of numbers from 1 to 10 int sum = 0; for (int num = 1; num <= 10; num++) { sum += num; // Add current number to sum } Console.WriteLine($"\nSum of numbers 1 to 10: {sum}"); } }
How a for loop works

for (start; keep going while; do this each time)

  • Start: Set up your counter (like "start counting at 1")
  • Keep going while: Check if you should keep going (like "while the number is less than 10")
  • Do this each time: Update your counter (like "add 1 to the number")

While Loop - When You Don't Know How Many Times

While loops keep going as long as something is true. They're great when you don't know in advance how many times you'll need to repeat something.

using System; class Program { static void Main() { // Simple while loop int counter = 1; Console.WriteLine("Counting with while loop:"); while (counter <= 5) { Console.WriteLine($"Counter: {counter}"); counter++; // Don't forget to update the counter! } // Guessing game with while loop int secretNumber = 7; int guess = 0; int attempts = 0; Console.WriteLine("\nGuess the number (1-10):"); while (guess != secretNumber) { Console.Write("Enter your guess: "); guess = int.Parse(Console.ReadLine()); attempts++; if (guess < secretNumber) { Console.WriteLine("Too low! Try again."); } else if (guess > secretNumber) { Console.WriteLine("Too high! Try again."); } } Console.WriteLine($"Congratulations! You guessed it in {attempts} attempts!"); } }
Infinite Loop Warning

Always ensure your while loop condition will eventually become false, or you'll create an infinite loop that runs forever! Make sure to update variables that affect the condition inside the loop.

Do-While Loop - Execute at Least Once

Do-while loops are similar to while loops, but they always execute the code block at least once before checking the condition.

using System; class Program { static void Main() { string playAgain; do { Console.WriteLine("Playing a game..."); Console.WriteLine("Game finished!"); Console.Write("Play again? (yes/no): "); playAgain = Console.ReadLine().ToLower(); } while (playAgain == "yes" || playAgain == "y"); Console.WriteLine("Thanks for playing!"); } }
Loop Control
  • break; - Exit the loop immediately
  • continue; - Skip to the next iteration
  • Use for when you know the number of iterations
  • Use while when you don't know the number of iterations
  • Use do-while when you need at least one execution

Chapter 6: Arrays and Collections - Organizing Data

Arrays and collections are like organized storage boxes for your data. Instead of having separate variables for each piece of data, you can store multiple related items together and work with them efficiently.

Arrays - Fixed-Size Collections

Arrays are containers that hold multiple values of the same type. Think of them like a row of numbered boxes where each box can hold one item.

using System; class Program { static void Main() { // Creating and initializing arrays int[] numbers = new int[5]; // Empty array of 5 integers string[] fruits = new string[] {"Apple", "Banana", "Orange"}; // Array with initial values double[] prices = {1.99, 2.49, 3.99, 0.99}; // Shorthand initialization // Accessing array elements (indexing starts at 0) Console.WriteLine("First fruit: " + fruits[0]); // Apple Console.WriteLine("Second fruit: " + fruits[1]); // Banana Console.WriteLine("Last fruit: " + fruits[fruits.Length - 1]); // Orange // Modifying array elements numbers[0] = 10; numbers[1] = 20; numbers[2] = 30; numbers[3] = 40; numbers[4] = 50; // Looping through arrays Console.WriteLine("\nNumbers array:"); for (int i = 0; i < numbers.Length; i++) { Console.WriteLine($"Index {i}: {numbers[i]}"); } // Using foreach loop (simpler for reading all elements) Console.WriteLine("\nFruits using foreach:"); foreach (string fruit in fruits) { Console.WriteLine($"• {fruit}"); } // Calculating sum and average double total = 0; foreach (double price in prices) { total += price; } double average = total / prices.Length; Console.WriteLine($"\nTotal price: ${total}"); Console.WriteLine($"Average price: ${average}"); } }
Array Properties
  • array.Length - Number of elements in the array
  • array[0] - First element (index 0)
  • array[array.Length - 1] - Last element
  • Arrays have fixed size - you cannot add or remove elements
  • All elements must be of the same type

Lists - Dynamic Collections

Lists are like flexible arrays that can grow and shrink as needed. They're more convenient when you don't know how many items you'll need to store.

using System; using System.Collections.Generic; class Program { static void Main() { // Creating lists List<string> names = new List<string>(); List<int> scores = new List<int> {85, 92, 78}; // Adding elements to a list names.Add("Alice"); names.Add("Bob"); names.Add("Charlie"); names.Add("Diana"); // Inserting at specific position names.Insert(1, "Eve"); // Insert at index 1 // Removing elements names.Remove("Bob"); // Remove by value names.RemoveAt(0); // Remove by index // Checking if element exists if (names.Contains("Charlie")) { Console.WriteLine("Charlie is in the list! 👋"); } // Displaying list contents Console.WriteLine("Current names in the list:"); for (int i = 0; i < names.Count; i++) { Console.WriteLine($"{i + 1}. {names[i]}"); } // Using foreach with lists Console.WriteLine("\nScores:"); foreach (int score in scores) { Console.WriteLine($"Score: {score}"); } // List properties Console.WriteLine($"\nNumber of names: {names.Count}"); Console.WriteLine($"Number of scores: {scores.Count}"); } }
When to Use Arrays vs Lists
  • Use Arrays: When you know the exact size and it won't change
  • Use Lists: When the size might change or you don't know the size in advance
  • Lists are more flexible but slightly slower than arrays
  • Arrays use less memory but are less convenient

Multi-dimensional Arrays

Sometimes you need to store data in a grid or table format. Multi-dimensional arrays let you organize data in rows and columns.

using System; class Program { static void Main() { // 2D array (like a table with rows and columns) int[,] grid = new int[3, 4]; // 3 rows, 4 columns // Filling the grid with values for (int row = 0; row < 3; row++) { for (int col = 0; col < 4; col++) { grid[row, col] = row * 10 + col; // Create pattern: 00, 01, 02, 03, 10, 11, etc. } } // Displaying the grid Console.WriteLine("2D Grid:"); for (int row = 0; row < 3; row++) { for (int col = 0; col < 4; col++) { Console.Write($"{grid[row, col]} "); } Console.WriteLine(); // New line after each row } // Jagged array (array of arrays) int[][] jaggedArray = new int[3][]; jaggedArray[0] = new int[] {1, 2}; jaggedArray[1] = new int[] {3, 4, 5}; jaggedArray[2] = new int[] {6}; Console.WriteLine("\nJagged Array:"); for (int i = 0; i < jaggedArray.Length; i++) { for (int j = 0; j < jaggedArray[i].Length; j++) { Console.Write($"{jaggedArray[i][j]} "); } Console.WriteLine(); } } }

Chapter 7: Methods and Functions - Reusable Code

Methods are like mini-programs within your program. They allow you to break down complex tasks into smaller, manageable pieces and reuse code without writing it multiple times. Think of methods as recipes - you write the recipe once and can use it many times.

Creating Simple Methods

Methods have a name, can take parameters (inputs), and can return a value (output). Let's start with simple methods that don't return anything.

using System; class Program { static void Main() { Console.WriteLine("=== Method Examples ==="); // Calling methods SayHello(); DisplayStars(); SayHello(); // Can call the same method multiple times // Methods with parameters GreetPerson("Alice"); GreetPerson("Bob"); DisplayNumber(42); DisplayNumber(100); // Methods with multiple parameters DisplayInfo("John", 25); DisplayInfo("Sarah", 30); } // Simple method with no parameters static void SayHello() { Console.WriteLine("Hello, World!"); } // Method that displays stars static void DisplayStars() { Console.WriteLine("*****"); } // Method with one parameter static void GreetPerson(string name) { Console.WriteLine($"Hello, {name}! Nice to meet you!"); } // Method with one parameter of different type static void DisplayNumber(int number) { Console.WriteLine($"The number is: {number}"); } // Method with multiple parameters static void DisplayInfo(string name, int age) { Console.WriteLine($"Name: {name}, Age: {age}"); } }
Method Structure

static void MethodName(parameters) { }

  • static: Makes the method accessible without creating an object
  • void: Means the method doesn't return a value
  • MethodName: The name you choose for your method
  • parameters: Input values the method needs (optional)

Methods That Return Values

Methods can also return values back to the code that called them. This is useful for calculations and data processing.

using System; class Program { static void Main() { // Using methods that return values int result1 = AddNumbers(5, 3); Console.WriteLine($"5 + 3 = {result1}"); int result2 = MultiplyNumbers(4, 7); Console.WriteLine($"4 × 7 = {result2}"); double area = CalculateCircleArea(5.0); Console.WriteLine($"Area of circle with radius 5: {area}"); string message = CreateGreeting("David", 28); Console.WriteLine(message); // Using returned values in calculations int sum = AddNumbers(10, 20) + AddNumbers(5, 15); Console.WriteLine($"Complex calculation: {sum}"); // Using boolean methods bool isEven = IsEven(8); Console.WriteLine($"Is 8 even? {isEven}"); bool isAdult = IsAdult(17); Console.WriteLine($"Is 17-year-old an adult? {isAdult}"); } // Method that returns an integer static int AddNumbers(int a, int b) { return a + b; // Return the sum } // Method that returns an integer static int MultiplyNumbers(int a, int b) { return a * b; // Return the product } // Method that returns a double static double CalculateCircleArea(double radius) { double pi = 3.14159; return pi * radius * radius; // π × r² } // Method that returns a string static string CreateGreeting(string name, int age) { return $"Hello {name}! You are {age} years old. 🎂"; } // Method that returns a boolean static bool IsEven(int number) { return number % 2 == 0; // Returns true if number is even } // Method that returns a boolean static bool IsAdult(int age) { return age >= 18; // Returns true if age is 18 or older } }
Return Statement Rules
  • Use return to send a value back from a method
  • The return type must match what you're returning
  • void methods don't return anything
  • You can return early from a method using return
  • Methods can have multiple return statements (but only one will execute)

Method Overloading - Same Name, Different Parameters

C# allows you to create multiple methods with the same name but different parameters. This is called method overloading.

using System; class Program { static void Main() { // Using overloaded methods DisplayMessage(); // No parameters DisplayMessage("Hello!"); // One string parameter DisplayMessage("Welcome", 3); // String and int parameters // Using overloaded calculation methods int sum1 = Add(5, 3); // Two integers double sum2 = Add(5.5, 3.2); // Two doubles int sum3 = Add(1, 2, 3); // Three integers Console.WriteLine($"Sum of 5 + 3 = {sum1}"); Console.WriteLine($"Sum of 5.5 + 3.2 = {sum2}"); Console.WriteLine($"Sum of 1 + 2 + 3 = {sum3}"); } // Overloaded methods with same name but different parameters static void DisplayMessage() { Console.WriteLine("Default message! 📢"); } static void DisplayMessage(string message) { Console.WriteLine($"Message: {message}"); } static void DisplayMessage(string message, int times) { for (int i = 0; i < times; i++) { Console.WriteLine($"{i + 1}. {message}"); } } // Overloaded Add methods static int Add(int a, int b) { return a + b; } static double Add(double a, double b) { return a + b; } static int Add(int a, int b, int c) { return a + b + c; } }
Method Naming Best Practices
  • Use descriptive names that explain what the method does
  • Use PascalCase for method names (first letter of each word capitalized)
  • Methods that return boolean values often start with "Is", "Has", "Can", etc.
  • Keep methods focused on a single task
  • Don't make methods too long - break complex tasks into smaller methods

Chapter 8: Object-Oriented Programming - Classes and Objects

Object-Oriented Programming (OOP) is a powerful way to organize and structure your code. It allows you to model real-world objects and their behaviors in your programs. Think of classes as blueprints and objects as things built from those blueprints.

Classes - The Blueprint

A class is like a template that defines what properties (data) and methods (behaviors) an object will have. It's the blueprint for creating objects.

using System; // Define a class called Person class Person { // Properties (data/attributes) public string Name; public int Age; public string City; // Constructor - special method that runs when creating a new object public Person(string name, int age, string city) { Name = name; Age = age; City = city; } // Methods (behaviors) public void Introduce() { Console.WriteLine($"Hi! I'm {Name}, I'm {Age} years old, and I live in {City}."); } public void HaveBirthday() { Age++; Console.WriteLine($"Happy Birthday, {Name}! You are now {Age} years old!"); } public bool IsAdult() { return Age >= 18; } } class Program { static void Main() { // Creating objects (instances) of the Person class Person person1 = new Person("Alice", 25, "New York"); Person person2 = new Person("Bob", 17, "Los Angeles"); // Using object methods person1.Introduce(); person2.Introduce(); // Checking if they are adults Console.WriteLine($"\nIs {person1.Name} an adult? {person1.IsAdult()}"); Console.WriteLine($"Is {person2.Name} an adult? {person2.IsAdult()}"); // Having a birthday person2.HaveBirthday(); Console.WriteLine($"Now is {person2.Name} an adult? {person2.IsAdult()}"); } }
Class Components
  • Properties: Data/attributes that describe the object
  • Constructor: Special method that initializes the object
  • Methods: Actions/behaviors the object can perform
  • Objects: Instances created from the class blueprint

Encapsulation - Protecting Data

Encapsulation is about controlling access to data and methods. It helps protect data and provides a clean interface for working with objects.

using System; class BankAccount { // Private fields - only accessible within the class private string accountNumber; private double balance; private string ownerName; // Public properties - controlled access to private fields public string AccountNumber { get { return accountNumber; } private set { accountNumber = value; } } public double Balance { get { return balance; } private set { balance = value; } } public string OwnerName { get { return ownerName; } set { ownerName = value; } } // Constructor public BankAccount(string owner, string accountNum, double initialBalance) { ownerName = owner; accountNumber = accountNum; balance = initialBalance; } // Public methods to interact with the account public bool Deposit(double amount) { if (amount > 0) { balance += amount; Console.WriteLine($"Deposited ${amount}. New balance: ${balance}"); return true; } else { Console.WriteLine("Invalid deposit amount!"); return false; } } public bool Withdraw(double amount) { if (amount > 0 && amount <= balance) { balance -= amount; Console.WriteLine($"Withdrew ${amount}. New balance: ${balance}"); return true; } else { Console.WriteLine("Invalid withdrawal amount or insufficient funds!"); return false; } } public void DisplayInfo() { Console.WriteLine($"Account: {accountNumber}"); Console.WriteLine($"Owner: {ownerName}"); Console.WriteLine($"Balance: ${balance}"); } } class Program { static void Main() { // Creating a bank account BankAccount account = new BankAccount("John Doe", "123456789", 1000.0); // Display initial info account.DisplayInfo(); // Perform transactions account.Deposit(500.0); account.Withdraw(200.0); account.Withdraw(2000.0); // Should fail // Display final info Console.WriteLine("\nFinal account status:"); account.DisplayInfo(); } }
Access Modifiers
  • public - Accessible from anywhere
  • private - Only accessible within the class
  • protected - Accessible within the class and derived classes
  • Use properties to control access to private fields
  • Encapsulation helps maintain data integrity

Inheritance - Reusing Code

Inheritance allows you to create a new class based on an existing class, inheriting its properties and methods while adding new ones.

using System; // Base class (parent) class Animal { public string Name; public int Age; public Animal(string name, int age) { Name = name; Age = age; } public virtual void MakeSound() { Console.WriteLine("Some animal sound"); } public void Sleep() { Console.WriteLine($"{Name} is sleeping... 😴"); } } // Derived class (child) - inherits from Animal class Dog : Animal { public string Breed; public Dog(string name, int age, string breed) : base(name, age) { Breed = breed; } // Override the MakeSound method public override void MakeSound() { Console.WriteLine($"{Name} says: Woof! Woof! 🐕"); } public void Fetch() { Console.WriteLine($"{Name} is fetching the ball! 🎾"); } } // Another derived class class Cat : Animal { public bool IsIndoor; public Cat(string name, int age, bool isIndoor) : base(name, age) { IsIndoor = isIndoor; } public override void MakeSound() { Console.WriteLine($"{Name} says: Meow! 🐱"); } public void Purr() { Console.WriteLine($"{Name} is purring... 😺"); } } class Program { static void Main() { // Creating different types of animals Dog dog = new Dog("Buddy", 3, "Golden Retriever"); Cat cat = new Cat("Whiskers", 2, true); // Using inherited methods dog.Sleep(); cat.Sleep(); // Using overridden methods dog.MakeSound(); cat.MakeSound(); // Using specific methods dog.Fetch(); cat.Purr(); // Polymorphism - treating different objects as the same type Animal[] animals = new Animal[] {dog, cat}; Console.WriteLine("\nAll animals making sounds:"); foreach (Animal animal in animals) { animal.MakeSound(); // Each animal makes its own sound } } }

Chapter 9: Exception Handling - Making Programs Robust

Exception handling is like having a safety net for your programs. It allows you to gracefully handle errors and unexpected situations instead of your program crashing. Think of it as having a backup plan when things go wrong.

Understanding Exceptions

Exceptions are events that occur during program execution that disrupt the normal flow of instructions. They can be caused by various factors like invalid input, file not found, division by zero, etc.

using System; class Program { static void Main() { // Example without exception handling (will crash) Console.WriteLine("=== Exception Examples ==="); // Division by zero exception try { int result = 10 / 0; Console.WriteLine($"Result: {result}"); } catch (DivideByZeroException ex) { Console.WriteLine($"Error: Cannot divide by zero! {ex.Message}"); } // Array index out of bounds exception int[] numbers = new int[] {1, 2, 3}; try { Console.WriteLine($"Number at index 5: {numbers[5]}"); } catch (IndexOutOfRangeException ex) { Console.WriteLine($"Error: Array index out of bounds! {ex.Message}"); } // Format exception (parsing errors) try { int number = int.Parse("abc"); Console.WriteLine($"Parsed number: {number}"); } catch (FormatException ex) { Console.WriteLine($"Error: Invalid number format! {ex.Message}"); } } }
Try-Catch Structure
  • try - Contains code that might cause an exception
  • catch - Handles the exception if it occurs
  • finally - Always executes, regardless of whether an exception occurred
  • You can have multiple catch blocks for different exception types

Practical Exception Handling

Let's see how to handle exceptions in real-world scenarios, like user input validation and file operations.

using System; class Program { static void Main() { Console.WriteLine("=== Safe Input Handling ==="); // Safe number input with exception handling int age = GetValidAge(); Console.WriteLine($"You entered: {age}"); // Safe division with exception handling double result = SafeDivide(10, 0); Console.WriteLine($"Safe division result: {result}"); // Array access with bounds checking int[] scores = new int[] {85, 92, 78}; int score = GetArrayElement(scores, 5); Console.WriteLine($"Retrieved score: {score}"); } // Method to safely get age input static int GetValidAge() { while (true) { try { Console.Write("Enter your age: "); string input = Console.ReadLine(); int age = int.Parse(input); if (age < 0 || age > 150) { throw new ArgumentException("Age must be between 0 and 150"); } return age; } catch (FormatException) { Console.WriteLine("Error: Please enter a valid number!"); } catch (ArgumentException ex) { Console.WriteLine($"Error: {ex.Message}"); } } } // Method to safely perform division static double SafeDivide(double numerator, double denominator) { try { return numerator / denominator; } catch (DivideByZeroException) { Console.WriteLine("Warning: Division by zero attempted. Returning 0."); return 0; } } // Method to safely access array elements static int GetArrayElement(int[] array, int index) { try { return array[index]; } catch (IndexOutOfRangeException) { Console.WriteLine($"Warning: Index {index} is out of bounds. Returning -1."); return -1; } } }

Finally Block - Cleanup Code

The finally block is used to ensure that certain code always executes, regardless of whether an exception occurs or not. It's commonly used for cleanup operations.

using System; class Program { static void Main() { Console.WriteLine("=== Finally Block Example ==="); // Example with finally block ProcessData(10); ProcessData(-5); // This will cause an exception } static void ProcessData(int value) { Console.WriteLine($"\nProcessing value: {value}"); try { if (value < 0) { throw new ArgumentException("Value cannot be negative"); } int result = value * 2; Console.WriteLine($"Processing successful! Result: {result}"); } catch (ArgumentException ex) { Console.WriteLine($"Error during processing: {ex.Message}"); } finally { // This code always executes Console.WriteLine("Cleanup: Processing completed (success or failure)"); Console.WriteLine("---"); } } }
Some tips for handling errors
  • Only catch errors you can actually do something about
  • Be specific about what errors you're catching
  • Always clean up in finally blocks
  • Give users helpful error messages
  • Don't use exceptions for normal program flow
