1. Getting Started - Your First Program

Every C# program starts with a Main method. This is where your code begins execution. Let's look at the classic "Hello World" example:

using System; class Program { static void Main() { Console.WriteLine("Hello, World!"); Console.WriteLine("Welcome to C# programming!"); } }
Understanding the Code
  • using System; - Imports the System namespace for basic functionality
  • class Program - Defines a class named Program
  • static void Main() - The entry point of your application
  • Console.WriteLine() - Outputs text to the console

2. Variables and Data Types

Variables are containers that store data. C# has several built-in data types, each designed for specific kinds of information:

Common Data Types

  • int - Whole numbers (-2,147,483,648 to 2,147,483,647)
  • double - Decimal numbers with high precision
  • string - Text data (sequences of characters)
  • bool - True or false values
  • char - Single characters
using System; class Program { static void Main() { // Different data types int age = 25; double price = 19.99; string name = "Sarah Johnson"; bool isStudent = true; char grade = 'A'; // Display the values Console.WriteLine($"Name: {name}"); Console.WriteLine($"Age: {age}"); Console.WriteLine($"Price: ${price}"); Console.WriteLine($"Is Student: {isStudent}"); Console.WriteLine($"Grade: {grade}"); } }
String Interpolation

Notice the $ before the string and the {} brackets. This is called string interpolation, a clean way to include variables inside strings.

3. User Input and Output

Interactive programs need to get input from users and display results. C# provides simple methods for console input and output:

using System; class Program { static void Main() { // Get user input Console.Write("Enter your name: "); string userName = Console.ReadLine(); Console.Write("Enter your favorite number: "); string numberInput = Console.ReadLine(); int favoriteNumber = int.Parse(numberInput); // Process and display results int doubledNumber = favoriteNumber * 2; Console.WriteLine($"\nHello, {userName}!"); Console.WriteLine($"Your favorite number is {favoriteNumber}"); Console.WriteLine($"Double that number is {doubledNumber}"); } }
Input Conversion

Console.ReadLine() always returns a string. Use int.Parse() or Convert.ToInt32() to convert strings to numbers.

4. Making Decisions with if/else

Programs often need to make decisions based on different conditions. The if/else statement allows your program to choose different paths:

using System; class Program { static void Main() { Console.Write("Enter your age: "); int age = int.Parse(Console.ReadLine()); if (age >= 18) { Console.WriteLine("You are an adult."); if (age >= 65) { Console.WriteLine("You qualify for senior discounts!"); } } else if (age >= 13) { Console.WriteLine("You are a teenager."); } else { Console.WriteLine("You are a child."); } // Multiple conditions if (age >= 16 && age < 18) { Console.WriteLine("You can drive but can't vote yet."); } } }
Common Comparison Operators
  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to
  • && Logical AND
  • || Logical OR

5. Loops - Repeating Actions

Loops allow you to repeat code multiple times. This is essential for processing lists of data, creating menus, or performing repetitive tasks.

For Loops

Use when you know how many times you want to repeat something:

using System; class Program { static void Main() { // Count from 1 to 10 for (int i = 1; i <= 10; i++) { Console.WriteLine($"Count: {i}"); } // Calculate factorial Console.Write("\nEnter a number for factorial: "); int number = int.Parse(Console.ReadLine()); int factorial = 1; for (int i = 1; i <= number; i++) { factorial *= i; } Console.WriteLine($"Factorial of {number} is {factorial}"); } }

While Loops

Use when you want to repeat until a condition changes:

using System; class Program { static void Main() { int attempts = 0; string password = ""; while (password != "secret123") { attempts++; Console.Write($"Attempt {attempts} - Enter password: "); password = Console.ReadLine(); if (password != "secret123") { Console.WriteLine("Incorrect password. Try again."); } } Console.WriteLine($"Access granted! It took you {attempts} attempts."); } }

6. Methods - Organizing Your Code

Methods (also called functions) help you organize code into reusable pieces. Instead of writing the same code multiple times, you can create a method and call it whenever needed.

using System; class Program { // Method to calculate area of a rectangle static double CalculateRectangleArea(double length, double width) { return length * width; } // Method to greet a user static void GreetUser(string name, int age) { Console.WriteLine($"Hello, {name}!"); Console.WriteLine($"I see you are {age} years old."); } // Method to check if a number is even static bool IsEven(int number) { return number % 2 == 0; } static void Main() { // Using our methods double area = CalculateRectangleArea(5.0, 3.0); Console.WriteLine($"Rectangle area: {area}"); GreetUser("Alice", 28); int testNumber = 7; if (IsEven(testNumber)) { Console.WriteLine($"{testNumber} is even"); } else { Console.WriteLine($"{testNumber} is odd"); } } }
Method Components
  • static - Can be called without creating an object
  • void - Returns nothing; other methods specify return type
  • Parameters - Input values the method needs
  • return - Sends a value back to the caller

7. Introduction to Classes and Objects

Object-Oriented Programming (OOP) is a fundamental concept in C#. Classes are blueprints for creating objects, which combine data (properties) and behavior (methods).

using System; // Define a class for representing a car class Car { // Properties (data) public string Make { get; set; } public string Model { get; set; } public int Year { get; set; } public double Mileage { get; set; } // Constructor (runs when creating a new car) public Car(string make, string model, int year) { Make = make; Model = model; Year = year; Mileage = 0; } // Methods (behavior) public void Drive(double miles) { Mileage += miles; Console.WriteLine($"Drove {miles} miles. Total mileage: {Mileage}"); } public void DisplayInfo() { Console.WriteLine($"{Year} {Make} {Model} - {Mileage:F1} miles"); } } class Program { static void Main() { // Create objects (instances of the Car class) Car myCar = new Car("Toyota", "Camry", 2020); Car friendsCar = new Car("Honda", "Civic", 2019); // Use the objects myCar.DisplayInfo(); myCar.Drive(150.5); myCar.Drive(75.2); friendsCar.DisplayInfo(); friendsCar.Drive(200.0); Console.WriteLine("\nFinal status:"); myCar.DisplayInfo(); friendsCar.DisplayInfo(); } }
Key OOP Concepts
  • Class - A blueprint that defines properties and methods
  • Object - An instance of a class with actual data
  • Properties - Data that belongs to the class
  • Methods - Actions that the class can perform
  • Constructor - Special method that runs when creating an object

8. Practical Example - Simple Calculator

Let's combine everything we've learned to build a simple calculator program:

using System; class Calculator { public static double Add(double a, double b) => a + b; public static double Subtract(double a, double b) => a - b; public static double Multiply(double a, double b) => a * b; public static double Divide(double a, double b) { if (b != 0) return a / b; else { Console.WriteLine("Error: Cannot divide by zero!"); return 0; } } } class Program { static void Main() { Console.WriteLine("=== Simple Calculator ==="); while (true) { Console.WriteLine("\n1. Add"); Console.WriteLine("2. Subtract"); Console.WriteLine("3. Multiply"); Console.WriteLine("4. Divide"); Console.WriteLine("5. Exit"); Console.Write("Choose an operation (1-5): "); string choice = Console.ReadLine(); if (choice == "5") { Console.WriteLine("Thanks for using the calculator!"); break; } if (choice == "1" || choice == "2" || choice == "3" || choice == "4") { Console.Write("Enter first number: "); double num1 = double.Parse(Console.ReadLine()); Console.Write("Enter second number: "); double num2 = double.Parse(Console.ReadLine()); double result = 0; string operation = ""; switch (choice) { case "1": result = Calculator.Add(num1, num2); operation = "+"; break; case "2": result = Calculator.Subtract(num1, num2); operation = "-"; break; case "3": result = Calculator.Multiply(num1, num2); operation = "*"; break; case "4": result = Calculator.Divide(num1, num2); operation = "/"; break; } Console.WriteLine($"Result: {num1} {operation} {num2} = {result}"); } else { Console.WriteLine("Invalid choice. Please try again."); } } } }
