Git Basics: Your First Steps into Version Control

January 15, 2024 5 min read Sunitha Kottayil
Git Version Control Beginner

What is Git?

Git is a distributed version control system that helps you track changes in your code over time. Think of it as a time machine for your projects!

Essential Git Commands

1. Setting Up Git

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

2. Creating a Repository

git init

This creates a new Git repository in your current directory.

3. Adding Files

git add filename.txt
git add .  # adds all files

4. Committing Changes

git commit -m "Your commit message"

5. Checking Status

git status

Best Practices

  • Write clear, descriptive commit messages
  • Commit often with small, logical changes
  • Always check git status before committing
  • Use .gitignore to exclude unnecessary files

Next Steps

Once you're comfortable with these basics, you can explore branching, merging, and remote repositories. Happy coding!

GitHub Workflow: From Clone to Pull Request

January 10, 2024 7 min read Sunitha Kottayil
GitHub Workflow Collaboration

Understanding GitHub Workflow

GitHub workflow is the process developers use to collaborate on projects. Here's how it works:

Step 1: Clone the Repository

git clone https://github.com/username/repository.git
cd repository

Step 2: Create a New Branch

git checkout -b feature/your-feature-name

Always create a new branch for your changes. This keeps the main branch clean.

Step 3: Make Your Changes

Edit your files, add new features, or fix bugs. Remember to:

  • Test your changes thoroughly
  • Follow the project's coding standards
  • Write clear, descriptive commit messages

Step 4: Commit and Push

git add .
git commit -m "Add new feature: description of what you added"
git push origin feature/your-feature-name

Step 5: Create a Pull Request

  1. Go to the repository on GitHub
  2. Click "Compare & pull request"
  3. Write a clear description of your changes
  4. Submit the pull request

Best Practices for Pull Requests

  • Keep pull requests small and focused
  • Write descriptive titles and descriptions
  • Link to relevant issues
  • Be responsive to feedback

C# Fundamentals: Variables, Types, and Control Flow

January 5, 2024 8 min read Sunitha Kottayil
C# Programming Beginner

Welcome to C#

C# is a powerful, object-oriented programming language developed by Microsoft. Let's start with the basics!

Variables and Data Types

Declaring Variables

// Integer
int age = 25;

// String
string name = "Sunitha";

// Boolean
bool isStudent = true;

// Double
double salary = 50000.50;

Type Inference with var

var message = "Hello World"; // string
var count = 10; // int
var price = 19.99; // double

Control Flow

If Statements

if (age >= 18)
{
    Console.WriteLine("You are an adult");
}
else
{
    Console.WriteLine("You are a minor");
}

Loops

// For loop
for (int i = 0; i < 5; i++)
{
    Console.WriteLine($"Count: {i}");
}

// While loop
int counter = 0;
while (counter < 3)
{
    Console.WriteLine($"Counter: {counter}");
    counter++;
}

Methods

public static void SayHello(string name)
{
    Console.WriteLine($"Hello, {name}!");
}

public static int Add(int a, int b)
{
    return a + b;
}
